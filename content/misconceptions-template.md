# 學生易錯概念 收集格式 Misconception Template

每個易錯概念一條，按課程單元分組。填好後放回此資料夾（可用 .md / .docx / Excel 任何格式，內容欄位一致即可）。

| 欄位 | 說明 | 例子 |
|---|---|---|
| 單元 Unit | 必修 I–V / 選修 I–IV | 必修 II 力和運動 |
| 概念 Concept | 中文 + 英文 | 作用與反作用 Action–reaction pairs |
| 錯誤想法 Misconception | 學生實際會怎樣說 / 怎樣答 | 「書放在桌上，重力和桌子的支持力是一對作用反作用力」 |
| 正確理解 Correct idea | 一兩句 | 作用反作用力必定作用在**兩個不同物體**上；重力與支持力都作用在書上，是平衡力 |
| 為何會錯 Why | 來源：日常直覺 / 公式誤用 / 圖像誤讀 / 中英術語混淆 | 兩力大小相等方向相反，外表像一對 |
| 能推翻它的情境 Counter-example | 一個學生「試一試」就會發現錯的情境（這會變成模擬裡的按鈕） | 把書放在加速上升的升降機：支持力 > 重力，但書對桌的壓力仍 = 支持力 |
| DSE 題目來源 Past paper | 年份、卷別、題號（如有） | 2019 Paper 1A Q12 |
| 優先度 Priority | 高 / 中 / 低（考試常見程度） | 高 |

## 例子 Example

- **單元**：必修 III 波動
- **概念**：位移-距離圖 vs 位移-時間圖 Displacement–distance vs displacement–time graphs
- **錯誤想法**：在位移-時間圖上量「波長」
- **正確理解**：位移-時間圖的橫軸是時間，一個週期的長度是 T 不是 λ；波長只能在位移-距離圖讀
- **為何會錯**：兩張圖形狀一樣，都是正弦曲線
- **能推翻它的情境**：同一列波同時顯示兩張圖，改變波速：位移-距離圖的 λ 變，位移-時間圖的 T 不變（頻率固定時）
- **DSE 題目來源**：（待補）
- **優先度**：高
