規格：`reference/11_Book2_難點與3D模擬器規格.md` 模擬器 2（拋體運動：水平與垂直的獨立性）　數據：11 個運行（`data/`）+ 15 個核數員補跑的運行（`audit/extra-data/`，用作者的 model/plan 以自訂參數導出，未讀其原始碼）、每運行 4000 幀（dt = 0.001 s）

## 結論
**物理數據、箭嘴、參數表、驗證條件全部通過。畫面兩項不通過：5.1、5.3。**

- 5.1　規格現象 1「一顆球自由下落，另一顆同時水平拋出」：13 張截圖全部沒有這個版本（截圖示範的是兩顆都水平拋出、初速 10 與 20 m s⁻¹）。數據層面我補跑了 companion = "drop"、θ = 0°、h = 20 m 的運行，兩球高度逐幀相等、同一幀落地（見 §5），即功能存在但無截圖證據。

## 6. 守恆量與邊界

**能量**（Eₖ + mgy，m = 1）：
- 無阻力 8 個官方／補跑運行：漂移 ≤ 3.0e-10 J（random-4，E ≈ 1142 J，相對 2.7e-13）；default 5.97e-13 J。通過。
- 空氣阻力運行：逐幀最大上升 0（單調不增），總損耗 random-0 175 J、random-1 518 J、random-2 109 J，與阻力做負功一致。

**空氣阻力時間軸**：meta.tf（畫面時間軸長度）= 1.5 × 無阻力 tf + 0.3 s（random-0/1/2 與補跑阻力運行的比值均為 1.5000）。我的 RK4 落地時刻 random-0 3.9635 s、random-1 11.99 s、random-2 4.973 s、edge-u50-θ45-h50-g10-air 7.174 s，均在時間軸內。（無阻力時 meta.tf = tf + 0.3 s。）

**邊界（補跑，全部 26 運行 obs / arrows / scales / meta 掃描非有限數 = 0）**：
- θ = 90°, h = 0：x = 2.8e-15 m（cos 90° 捨入），tf 3.0581 = 2u/g，k = 0.872，無 NaN。

- u = 50, θ = 45°, h = 50, g = 1.6：4 s 內 y 升至 178.6 m 未落地，meta.tf 45.87 s，k = 0.0062，數值正常。

- θ ≤ 0° 且 h = 0（θ = −30° 或 θ = 0°，u 任意）：tf = 0，首幀即 landedA = 1，所有讀數（含 vₓ、v、Eₖ）為 0，無箭嘴，時間軸 0.3 s。這是 y = h + u sinθ·t − ½gt² 在 t > 0 立即為負的正確結果，但學生把 θ 拉到 0° 而 h 仍是預設 0 時畫面上甚麼都不會發生（見 §7）。

## 7. 規格待釐清

1. **H 公式對負投射角**：規格 H = h + u² sin²θ / 2g 在 θ < 0 時給出高於發射點的值（random-3：43.516 m），但實際最高點就是發射點 h（43.218 m）。數據採用後者（obs.H = h）。建議規格註明 θ < 0 時 H = h。
2. **落地後的讀數約定**：數據把位置與速度凍結在落地瞬間（v = 15.0、vᵧ = −9.64 m s⁻¹），但 ax、ay 在同一刻變為 0（ipad-portrait.png 讀數「a 加速度（垂直）0.00 m s⁻²」而 vᵧ 仍顯示 −9.64）。規格未寫落地後顯示甚麼；速度非零而加速度為零並存，建議老師決定（例如落地後速度也顯示 0，或加速度保持 −g 並註明「落地前」）。
3. **θ ≤ 0° 且 h = 0**：飛行時間 0，畫面無動作。規格參數表容許 θ 到 −30° 而 h 預設 0，兩者組合無意義；建議介面在 h = 0 時限制 θ ≥ 1°，或 θ ≤ 0 時提示須設 h > 0。
4. **空氣阻力形式**：規格未列，數據用 a = −k v|v|，k = 0.01 m⁻¹（manifest.beyondSpec 已列待老師定奪）。本核數只驗證數據與此形式自洽，不評定形式是否合適。
5. **第二顆球的預設**：預設 companion = "fast"（兩顆都水平拋出），規格現象 1 寫的是「自由下落」對「水平拋出」；情境 1 亦用 "fast"。若老師要以規格字面版本作 B8.1 核心示範，情境 1 應改為 companion = "drop"（θ = 0°、h > 0）並補截圖。
6. **時間軸長度**：meta.tf = 1.5 × 無阻力 tf + 0.3 s（阻力）或 tf + 0.3 s（無阻力）。「+0.3 s」為落地後停留，規格未寫；不影響物理。
