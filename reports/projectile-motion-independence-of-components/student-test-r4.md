# 學生試用：http://localhost:5180/#/sim/projectile-motion-independence-of-components
裝置：電腦 / iPad 直向

## 第一眼
一打開個網頁，畫面中間已經有一個黑色嘅「炮」向右上斜射出一個橙色波，波已經在半空飛（唔係靜止畫面，一開就自動開始播）。上面有暫停/逐格/重播/還原預設幾個按鈕，仲有個「跳到 t=」嘅拉桿同一個時間顯示。右邊一大堆滑桿（初速、投射角、發射高度、重力加速度、質量）同埋一堆checkbox。下面有三個細細嘅圖（側視、俯視、動能-時間）。

第一眼我唔知呢個係做乜嘅，估係中學物理「拋體運動」個模擬器，但唔知要由邊個掣開始撳。因為波已經自己射出咗，所以我第一步淨係「等」佗睇佗落地，冇撳任何掣都得。如果老師無講「等波落地」，我可能會即刻亂撳滑桿，唔知會唔會影響咗個「原本」嘅示範。

## 老師叫我做的事
### 1. 等球落地，讀水平距離、飛行時間，睇時鐘停唔停
步驟：乜都冇撳，淨係等（大約3-6秒）。
期望：波跌到地下之後，時間唔再郁，可以讀到個距離。
實際：波跌到地下（y=0.00 m）之後，個「t = ...s」同「跳到t=」嗰個數字定咗在 1.97 s，冇再變。水平距離 x = 22.6 m。等多幾秒再睇都係一樣，證明真係停咗，唔係卡住。
嘗試次數：1次（睇3次screenshot確認冇再變）。
做到 / 做不到：做到。

### 2. 第二顆球設「水平初速加倍」，重播，睇是否同時落地，讀兩球水平距離
步驟：撳右邊「第二顆球」嗰行嘅「水平初速加倍」按鈕 → 撳「重播」。
期望：兩個波應該同一時間跌落地下（因為得水平速度唔同，垂直嗰part一樣）。
實際：撳咗之後自動開始播（唔撳重播佗都自己播喎，第一次撳完「水平初速加倍」個sim已經開始行）。等到落地，時鐘停在 t = 1.97 s，同第1題一樣。第一個波（橙色）x = 22.6 m，第二個波（藍色）要chur落去先見到，寫住「x₂ 第二顆球水平距離 = 45.2 m」。兩個波跌地嗰刻睇落真係一樣（時鐘一齊停）。
嘗試次數：2次（第一次撳完已經有結果，之後多撳一次「重播」確認）。
做到 / 做不到：做到，但係「x₂」呢個數字要scroll落去先見到，唔係一眼見到，第一次搵咗好耐。

### 3. 開「空氣阻力」，重播，睇路徑/讀數/箭嘴變化；再拉質量到最大再睇
步驟：撳「空氣阻力」checkbox → 撳「重播」→ 等落地。再撳質量滑桿拉到最大（5 kg）。
期望：有阻力嘅話波應該飛得近啲、路徑唔對稱、跌得快啲；質量大啲阻力影響應該細啲（波應該飛得返近返原本）。
實際：
- 開咗空氣阻力：波飛短咗，t = 1.80 s（之前1.97s），x = 16.0 m（之前22.6m）。睇條路徑，落嗰邊比起飛嗰邊斜好多，唔似之前對稱嘅拋物線。動能圖個底部唔一樣，唔再係一條乾淨嘅U形。
- 拉質量去5kg（最大）：波又飛遠啲、飛耐啲返嚟：t = 1.93 s，x = 20.9 m。同冇阻力嗰陣（1.97s / 22.6m）愈嚟愈似，睇條路徑又變得對稱少少。W（重量）箭嘴變粗/長咗。
嘗試次數：大約4次（開checkbox一次、撳重播一次、拉質量一次、等落地3次）。
做到 / 做不到：做到。但中途撞到一個好大問題（見下面「卡住」），試緊呢題個「第二顆球=水平初速加倍」畫面（第2題）加埋開空氣阻力之後，藍色波（第二顆）喺畫面上明明仲喺半空冇跌落地，但個「y₂ 第二顆球高度」讀數已經寫0.00m，而個時鐘已經停咗——即係畫面同數字對唔上。

### 4. 開「頻閃照片模式」，睇邊個視窗變咗
步驟：撳「顯示」欄嗰個「頻閃照片模式（側視變黑底）」checkbox。
期望：估佗會令個側視窗變成一張黑底相，好似書上果啲頻閃相咁。
實際：下面三個細窗，最左邊嗰個（本來叫「側視投影（垂直運動）」）變成黑底，上面顯示一串白色小圓點沿住拋物線排，標題變成「頻閃照片（每0.1s）」。其餘兩個窗（俯視、動能圖）冇變。
嘗試次數：1次。
做到 / 做不到：做到，一撳就見到，幾直接。

### 5. 左邊嗰部器材係乜、上面紅線同角度數字係乜
我睇畫面：左邊有一個黑色細細嘅裝置，好似一支斜放嘅炮/發射管，裝喺一個三角架上，指向右上方。上面有條紅色斜線，旁邊寫「θ = 40°」。
我以為：呢個係「發射器」（一支炮或者彈弓咁嘅裝置），用嚟射個波出去。嗰條紅線同數字應該係用嚟顯示個發射管而家斜咗幾多度（即係「投射角」），啱啱好個數字（40°）同右邊滑桿嗰個「θ 投射角」嘅數值一樣，改動嗰個滑桿個角度都會跟住轉，所以我肯定嗰條線即係代表個發射角度嘅指示線。

## iPad 上的問題
- 版面變成一條直落，3D畫面、三個細圖、參數欄全部疊埋一齊，要不停scroll先睇到晒（由頭scroll到「顯示」checkbox果度大概要scroll 2-3次）。
- 3D畫面本身喺iPad寬度變到幾窄，睇個炮/波都細咗，但基本上睇得到，冇被遮住。
- 撳checkbox、按鈕嗰啲位都夠大，手指按得中，冇問題。
- 最大問題：喺iPad模式，撳咗「質量」滑桿之後撳個鍵盤「End」（想拉去最大），個sim突然整頁彈返上頂、3D畫面一嗰間變成全白（乜都冇畫），要等多幾秒先見到波再出現。之後檢查發現全部設定（空氣阻力、質量、第二顆球）已經自動變返晒做預設值，同我之前設落嘅完全唔一樣——即係做嘅嘢無啦啦被reset咗，同電腦版遇到嘅果個bug（見下面）一樣。
- 冇見到要橫向scroll嘅地方（版面冇爆出畫面）。

## 我卡住的地方（按嚴重程度排）
1. **（最大問題）操作中會無啦啦全部reset**：喺電腦版，撳完「逐格0.05s」（喺動畫已經播完嗰陣撳）之後，成個sim嘅設定（空氣阻力checkbox、第二顆球選擇、質量）自動變返晒做預設值，冇任何提示話「已重設」。喺iPad版一樣，撳完質量滑桿再撳鍵盤"End"之後，又發生完全一樣嘅reset。呢個好confusing，做緊嘅實驗會無啦啦冇咗，要由頭嚟。
2. **v / vx checkbox 撳走個波本身會消失**：喺「顯示」欄撳走「速度 v」或者「速度水平分量 vₓ」呢兩個checkbox，唔止箭嘴唔見，連個橙色波（主角）自己都由3D畫面完全消失，要再撳返先見到波返嚟。呢個好唔對路，個checkbox標籤講嘅係「顯示速度」，冇講會連波都唞埋。
3. **畫面同數字對唔上**：第2題（第二顆球=水平初速加倍）加開空氣阻力嗰陣，藍色嗰個波明明喺3D畫面仲喺半空（未跌到地下），但讀數欄寫「y₂ 第二顆球高度 = 0.00 m」，個時鐘又已經停咗——即係個readout話跌咗地，但畫面睇落未跌。唔知邊個先啱。
4. **g（重力加速度）、速度（播放快慢）呢兩個下拉選單完全撳唔到**：撳落去冇彈出選單，個sim淨係自己由頭重播一次，數值一直冇變過。試過用滑鼠click、鍵盤上下鍵、Enter、Home/End都改唔到。如果要睇「月球」「火星」個效果，我完全做唔到。
5. **x₂/y₂ 數字要scroll先見到**：第二顆球嘅讀數放喺個「讀數」panel好底，第一次搵咗好耐先發現要scroll落去先有。
6. 一開頁面波已經自動射出，冇提示第一步應該撳乜，如果唔係跟老師逐項讀題目，我唔知由邊度開始。
7. 「a 加速度（垂直）」波落地之後變0.00，同我以為半空應該係-9.81呢個認知有出入，冇解釋做乜落地會變0（雖然我明可能係「已經停咗」，但畫面冇講清楚）。

## console 錯誤
用 read_console_messages 揀晒睇（連埋 onlyErrors=true 同全部），冇見到紅色 error。只有黃色 warning：
```
[warn] THREE.Clock: This module has been deprecated. Please use THREE.Timer instead.
```
其餘都係 [debug] 同 [info] 嘅 vite 開發伺服器訊息（hot update、connecting/connected、React DevTools 提示），唔係錯誤。
