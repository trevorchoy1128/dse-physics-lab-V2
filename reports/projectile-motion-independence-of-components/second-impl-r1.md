# 第二實作比對：projectile-motion-independence-of-components

積分方法：無空氣阻力 → 規格解析解（x = u cosθ·t，y = h + u sinθ·t − ½gt²，v_y = u sinθ − gt），落地時刻用二次方程精確解；有空氣阻力 → 古典四階 Runge–Kutta（RK4），落地步內以二分法（40 次）對步長分數求 y = 0 的根。
步長：dt = 0.001 s（取自 index.json）。幀數：4000（t = 0 至 3.999 s）。
空氣阻力形式依 manifest.beyondSpec：a = −g ŷ − k v|v|，k = 0.01 m⁻¹，質量 1 kg。

實作檔案（純 JavaScript，未看 model.ts / plan.ts / 測試）：
- `reports/projectile-motion-independence-of-components/second-impl/model.mjs` — 模型
- `reports/projectile-motion-independence-of-components/second-impl/run.mjs` — 依 index.json 產生 11 個 `<run>.json`
- `reports/projectile-motion-independence-of-components/second-impl/compare.mjs` — 逐幀比對（輸出 compare-table.md、compare-summary.json）
- `reports/projectile-motion-independence-of-components/second-impl/checks.mjs` — 額外檢查

## 結論

**一致。** 11 個運行、127 個（運行 × key）組合全部通過：

- 無空氣阻力 8 個運行（容限 1e-6）：最大絕對誤差 2.5e-10（random-4 的 Ek，量值約 500，相對 5e-13），其餘皆 ≤ 5e-11。
- 有空氣阻力 3 個運行（容限 1e-4）：最大絕對誤差 3.3e-13（t 的累加浮點漂移），x、y、vx、vy、ax、ay、Ek 的差更小。
- 落地時刻：7 個落地的運行落地幀索引完全相同，落地 t 差 ≤ 3.3e-13 s（容限 2 dt = 0.002 s）；random-1、random-2、random-4 兩者皆在 4 s 內未落地。
- t = 0 幀：兩者皆與初始條件（x = 0、y = h、vx = u cosθ、vy = u sinθ、t = tf = 0）零殘差。

有空氣阻力的三個運行一致到 1e-13，這只可能是兩邊都用 RK4、同一 dt 的結果，因此逐幀一致本身不能證明積分誤差合格；下面「額外檢查」以 dt/10 收斂測試與 θ = 90° 的二次阻力解析解另行驗證。

## 不一致的判斷

無不一致。以下是為了確保「一致」不是「同時錯」而做的獨立驗證：

1. **無阻力運行 vs 規格解析解**：第二實作直接代入規格方程，因此主實作與解析解的差即上表誤差（≤ 2.5e-10）。落地時刻與 (u sinθ + √(u² sin²θ + 2gh))/g 一致到 1e-13。
2. **主實作數據的內部一致性**（不經第二實作，直接檢查 data/*.json）：
   - 無阻力 8 運行 v_x 全程與 v_x(0) **完全相等**（差 0），符合規格驗證條件（容許 1e-6）。
   - 無阻力機械能 Ek + g·y（m = 1）全程守恆，最大漂移 3e-10（random-4）。
   - 有阻力 3 運行每幀的 (ax, ay) 與 (−k v_x|v|, −g − k v_y|v|) 的殘差 ≤ 3.6e-15，且機械能單調遞減。
   - companion = fast 的 2 運行：yB − y 全程 **恰為 0**、xB − 2x 全程恰為 0（規格現象 1「垂直位置永遠相同」）。
   - 最高點（|v_y| 最小幀）：Ek − ½v_x² ≤ 2.7e-6、H − y ≤ 2.8e-7，均為幀解析度（½(g·dt/2)² ≈ 1e-5 的上界）以內，非模型誤差；落地速率 − u = 0（h = 0 運行），符合「落地速率等於初速」。
   - 跨運行射程對稱：R(40°, u = 15)·(20/15)² 與 R(50°, u = 20) 差 3e-12（θ 與 90° − θ 射程相同，R ∝ u²）。
   - default 上升時間 0.983（幀解析度）對 tf/2 = 0.98286。
3. **有阻力模型獨立驗證**（第二實作自身）：
   - θ = 90°、u = 20、h = 30 與二次阻力的解析解（上升 v = v_t tan(arctan(u/v_t) − gt/v_t)，下降 v = −v_t tanh(gt/v_t)，v_t = √(g/k)）比對：max|Δv_y| = 1.1e-11、max|Δy| = 2.0e-11。
   - dt = 0.001 對 dt = 0.0001 收斂：random-0/1/2 的 x、y、vx、vy 差 ≤ 9.2e-13，落地 t 差 ≤ 1.1e-14。RK4 在此 dt 的截斷誤差遠低於 1e-4 容限。

## 額外檢查

### 量綱
- x = u cosθ·t：m s⁻¹ · s = m。y 的三項：m、m s⁻¹·s、m s⁻²·s² 皆為 m。v_y = u sinθ − gt：m s⁻¹。H = h + u² sin²θ/2g：m + (m² s⁻²)/(m s⁻²) = m。
- 阻力 a = −k v|v|：[k] = m⁻¹，m⁻¹ · (m s⁻¹)² = m s⁻² ✓。終端速率 √(g/k) = √(9.81/0.01) = 31.32 m s⁻¹，與 manifest 所述「約 31」相符；模擬中由 1000 m 高處下落 10 s 後 v = 31.21，向 31.32 單調趨近。
- Ek = ½mv²，m = 1 kg → J；主實作 default 的 Ek(0) = 112.5 = ½·15² ✓。
- 角度：controls 以度輸入，兩實作內部用弧度（t = 0 幀 vx = 15 cos 40° = 11.4907 一致）。

### 對稱
- R(20°) − R(70°) = −1.8e-15，R(30°) − R(60°) = −3.6e-15（h = 0，無阻力）。
- 掃描 40°、44°、45°、46°、50°：R = 22.587、22.922、22.936、22.922、22.587，45° 最大且對 45° 鏡像相等。
- 上升／下降時間相等、落地速率 = 初速（見上）。

### 極限
- **t = 0**：所有運行 t = 0 幀零殘差；有阻力 θ = 0 時 t = 0 的 ax = −k u² = −1.00（u = 10）、ay = −g、v_y = 0，符合方程。
- **θ = 0、h = 0**：一開始已在地面，輸出 t = tf = 0、x = y = vx = vy = 0、ax = ay = 0、H = 0。θ = −30°、h = 0 同樣；companion = drop 時 B 亦在地面。h = 0、θ = 40° 且 companion = drop：主球正常飛行、B 由第一幀起 yB = 0、EkB = 0（B 由靜止釋放於地面）。
- **companion = drop、h = 20、θ = 30°**（index.json 無此組合，僅第二實作自測）：B 在 2.0193 s = √(2h/g) 落地並凍結，主球在 2.9237 s（解析值相同）落地後整體 t 才凍結。
- **k → 0**：air = true 並把 k 設為 1e-4、1e-6、1e-8，與無阻力解析解的最大差為 5.7e-2、5.7e-4、5.7e-6，落地 t 差 −1.6e-4、−1.6e-6、−1.6e-8，皆與 k 成正比，k → 0 時收斂到規格方程。
- **g 增大 → 飛行時間縮短**：θ = 40°、u = 15 時 g = 9.81 落地 1.9657 s（= 2u sinθ/g）；g = 1.6 時解析 12.05 s，4 s 內未落地（與 random-4、g = 3.7 的行為一致）。
- **u 增大**：射程 ∝ u²（跨運行檢查差 3e-12）。
- **θ = 90°**：cos 90° 在浮點下為 1.2e-16，ux ≈ 1.2e-15，x 全程 ≤ 4e-15，可視為 0。

## 規格待釐清

1. **空氣阻力的形式與係數**：規格只寫「開／關」。主實作與本比對都用 a = −k v|v|、k = 0.01 m⁻¹（終端速率 31.3 m s⁻¹）。注意 u 的上限 50 m s⁻¹ 超過終端速率：u = 50 時起始阻力加速度 25 m s⁻² 大於 g，球會像羽毛球般急劇減速。若老師希望阻力只是「輕微修正」，k 應再小一個數量級（例如 0.001 m⁻¹，終端速率約 99 m s⁻¹）。
2. **tf 的定義**：主實作 tf 恆等於 t（兩者同時凍結在最後一顆球落地）。有第二顆球且落地時刻不同時（companion = drop、θ > 0、h > 0），主球落地後 tf 仍隨 B 前進；「飛行時間」面板要顯示哪顆球的落地時刻，規格未寫。index.json 沒有 drop 的運行，此情況未經兩實作比對。
3. **「水平初速加倍」的第二顆球**：規格迷思表只說「水平初速不同」，「兩倍」是開發端定的（manifest 已列）。
4. **h = 0 且 θ ≤ 0 時的處理**：規格未寫；兩實作都令球一開始在地面（tf = 0，速度歸零）。若老師希望 θ = 0、h = 0 仍可「沿地面滾」或視為無效輸入，需明示。
5. **H 在向下射（θ < 0）時 = h**：規格公式 H = h + u² sin²θ/2g 對 θ < 0 會給出大於 h 的值，兩實作都改為 H = h（最高點就是發射點）。建議規格註明。
6. **非 observe 輸出的提醒**：主實作 data 檔的 `meta.tf` 在有阻力運行不等於 obs.tf（例如 random-0 的 meta.tf = 5.859 而實際落地 3.963；數值等於 1.5 × 無阻力落地時刻 + 0.3，看似播放時長）。若任何介面把 meta.tf 當「飛行時間」顯示會出錯；此項不在比對範圍，僅提醒。
