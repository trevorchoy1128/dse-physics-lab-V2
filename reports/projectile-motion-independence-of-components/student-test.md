# 學生試用：http://localhost:5180/#/sim/projectile-motion-independence-of-components
裝置：電腦（預設視窗，冇改過大小） / iPad 直向（768×1024）

## 第一眼
未按任何嘢之前，個畫面已經自動喺度播緊：一個灰色斜斜嘅背板、地下有網格、兩顆波（橙色、藍色）已經飛緊，留低一條橙色軌跡（頻閃小波點）。上面有標題「拋體運動：水平與垂直的獨立性」，仲有幾個藍色數字提示框（1,2,3）解釋緊個畫面。

我第一眼以為呢個係「睇兩粒波點樣同時飛」嘅動畫展示，唔係好肯定要「按邊度」先開始，因為個波已經自己喺度郁緊，冇一個好明顯嘅「開始」掣（暫停掣已經顯示緊「暫停」，即係話而家係播放緊）。第一步應該係㩒「暫停」定係影住個畫面睇下去，唔係太直覺。落面仲有三個細細嘅圖表（側視/俯視/動能-時間），同一個好長嘅設定區域，但要scroll先見到，一開始睇唔出落面仲有嘢。

## 老師叫我做的事

### 1. 兩顆球飛咗幾遠、係咪同時落地
步驟：㩒「重播」由頭嚟過，等兩顆波飛完落地，睇3D畫面同下面嘅俯視圖。
期望：見到兩個波分別喺邊度停低，讀到兩個距離。
實際：橙色波清楚見到停喺 `x = 22.6 m`（3D畫面有個文字框寫住）。藍色波（老師話水平初速係橙色兩倍）睇落飛得遠好多、成個畫面右邊，但**冇任何數字框話俾我知佢實際飛咗幾遠**——3D畫面淨係得一個x數值框，好似永遠都係跟住橙色波。落面「讀數」個panel（電腦版要scroll好耐先見到，仲要係當我搵到嗰陣）都只係得一行「y₂ 第二顆球高度 = 0.00 m」，冇「x₂」呢類數值，所以我response唔到藍色波實際飛咗幾多米，淨係用肉眼喺個俯視小圖度度，覺得大概係橙色嘅兩倍咁遠（但唔肯定，冇把尺）。
係咪同時落地：兩個波嘅頻閃波點軌跡睇落係喺動畫停低嗰下一齊停低，落面「y₂ 第二顆球高度」都係 0.00 m，同橙色嘅 y 都係 0.00 m，所以睇落係同時。但有一個好confusing嘅地方：動畫「停低」之後，右上角個 `t = ... s` 個計時器仲自己一路跳（由2.27跳到3.4、5.7…），啲波就完全冇郁，搞到我一開始以為藍色波仲喺度飛緊（因為3D視角好斜，佢個位置睇落好似仲浮喺半空，冇貼地），諗咗好耐先明原來個view只係鏡頭斜先睇落咁樣，個波應該已經落地。
嘗試次數：大概 6-7 次（重播、等、screenshot、放大睇、諗到底佢有冇落地）。
做到 / 做不到：**部分做到**——橙色波嘅距離讀到（22.6 m），藍色波距離讀唔到實際數字（只可以用眼估），同時落地呢點都係靠自己推斷唔係直接讀到答案。

### 2. 第二顆球設「無」，搵最高點速度
步驟：想搵「第二顆球」嗰個設定掣，喺畫面度scroll落去搵。
期望：見到一組掣（無/同時自由下落/水平初速加倍），撳「無」。
實際（電腦，預設視窗）：**搵唔到！** scroll落去到3個細圖之後，成個畫面係一大撻空白（乜都冇，淨係背景色），不論點scroll、scroll幾多下都係咁，一路scroll到底都係空白，冇再出返嚟。用鍵盤Tab㩒都可以感覺到個焦點喺郁（頁面自己識scroll去某個位置），但去到嗰位仍然係空白，睇唔到任何掣、任何滑桿、任何數字。呢個係我試極都做唔到嘅地方。
（我之後為咗完成報告用咗其他方法確認個掣其實有效——但呢個唔係一個普通學生用滑鼠、手指可以做到嘅方法，所以就電腦呢個視窗嚟講，呢個task**做唔到**，因為個panel成塊睇唔到。）
實際（iPad 768×1024）：呢次冇問題！Scroll落去可以完整見到「參數」「第二顆球（同時發射）」「顯示」「讀數」成個panel，掣同數字都好清楚。撳咗「無」之後，得返一個橙色波。跟住用「逐格 0.05 s」呢個掣一格一格撳，睇住 `y = ...m` 個數值，撳到最高（y≈4.72 m，t≈1.05s，呢個時候垂直速度嘅箭嘴消失咗，得返水平箭嘴，睇得出係最高點）。落到落面「讀數」個panel讀到：
  - v 合速率 = **11.5 m s⁻¹**
  - vₓ 速度水平分量 = 11.5 m s⁻¹
  - vᵧ 速度垂直分量 = -0.659 m s⁻¹（接近0）
嘗試次數：電腦嘗試咗大約10次scroll＋等（全部失敗），iPad嘗試5-6次（逐格搵最高點）先搵到。
做到 / 做不到：**電腦做不到**（panel睇唔到）；**iPad做到**，答案：合速率約 11.5 m/s。

### 3. 邊個角度射得最遠
步驟：老師提示「有個可以開啟嘅選項會幫到你」。喺「顯示」嗰行度見到（iPad先見到；電腦要靠盲搵）有個「各角度射程比較」剔選格，撳咗佢。
期望：畫面會顯示幾條唔同角度嘅拋物線畀我比較邊條飛得最遠。
實際：撳咗之後，3D畫面即刻多咗幾條虛線弧線，標住 15°、30°、45°、60°、75°，其中 45° 嗰條特別粗、顏色唔同（藍綠色）。睇個落地位置，45° 嗰條明顯係5條入面落地最遠嗰條（60°、75° 落地反而更近，因為飛得太高）。
嘗試次數：3次（搵到個剔選格、撳、睇圖）。
做到 / 做不到：**做到**，答案係 **45°**。呢個係全個報告入面少數電腦版都算做到嘅任務——因為雖然嗰個剔選格本身喺睇唔到嘅空白區，但撳咗之後嘅結果（幾條比較線）係畫喺3D畫面呢個「睇得到」嘅區域，所以就算搵掣搵得辛苦，睇答案冇問題。

## 每個控制項我以為是做甚麼

| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| 暫停 / 播放 | 開始或停止個動畫 | 撳一下真係會停低/繼續，符合預期 |
| 逐格 0.05 s | 一步步行前0.05秒，方便睇慢動作 | works，每撳一下個波郁一格，好用嚟搵最高點 |
| 重播 | 由頭再嚟一次 | 撳咗即刻返去t=0，符合預期 |
| 還原預設 | 我以為係「返去最初打開網頁嗰個畫面」 | 撳完之後，有時見到同開場一樣嘅兩球高拋，有時（喺我打亂咗其他設定之後）撳完出嚟嘅係一條好扁嘅單一軌跡（θ好似變成5度），完全唔似最初嗰個畫面，搞到我以為個掣壞咗／唔知「預設」實際係邊set數值 |
| 速度（0.1×~2×）落單 | 應該係調較動畫播放快慢 | 冇認真逐個試，睇標籤都幾清楚係咁 |
| 跳到 t = （滑桿＋數字格） | 掕住個滑桿／打個數字可以跳去指定時間 | 用滑桿掕/撳係work嘅；但直接喺個數字格打字然後撳Enter，個結果好唔穩定——試過打「1.00」入去，Enter完個時間變咗做0.71s，仲有一次搞到成個模擬設定（角度、第二個波）都變咗，唔知點解，好confusing |
| u 初速 / θ 投射角 / h 發射高度（滑桿） | 分別調較初速、射出角度、發射高度 | 冇逐個滑，但由讀數變化（u=15, θ=40, h=0）睇得出個標籤同數值係啱嘅 |
| g 重力加速度（落單：地球/月球/火星） | 揀邊個星球嘅地心吸力 | 冇試切換，但標籤清楚 |
| 空氣阻力（剔選格） | 開唔開空氣阻力嘅效果 | 冇試撳，唔知開咗實際畫面會點變 |
| 第二顆球（無 / 同時自由下落 / 水平初速加倍） | 揀第二個波用邊種方式同時發射 | 撳「無」得返一個波，撳「水平初速加倍」多返個波出嚟且跑快兩倍，符合標籤意思 |
| 顯示：速度v／vₓ／vᵧ／加速度a／重量W／空氣阻力箭嘴／頻閃影像／路徑 | 應該係開關3D畫面度嗰啲箭嘴／點標記 | 冇逐個剔試，唔知邊個箭嘴對應邊個剔選格（同一時間睇到好幾條綠色箭嘴，好難分邊條係邊個） |
| 各角度射程比較（剔選格） | 顯示唔同角度嘅比較線 | 撳咗有效，加咗5條虛線喺3D畫面，好清楚見到邊個角度飛得遠 |
| 試試看（下面5句說話） | 一開始以為係5粒可以撳嘅掣，撳落去可能會有反應 | 試撳咗（電腦、iPad都試），完全冇反應，睇落只係5句畀你自己諗嘅講法，唔係按鈕 |

## 畫面上的數字

| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| `t = ... s`（右上角） | 現在動畫播放到第幾秒 | 有，s |
| `x = ... m`（3D畫面） | 波飛咗嘅水平距離 | 有，m |
| `y = ... m`（3D畫面） | 波而家嘅高度 | 有，m |
| t 飛行時間 | 由發射到落地嘅總時間 | s |
| x 水平距離 | 同上面3D嗰個x一樣 | m |
| y 當前高度 | 同上面3D嗰個y一樣 | m |
| vₓ 速度水平分量 | 水平方向嘅速度 | m s⁻¹ |
| vᵧ 速度垂直分量 | 垂直方向嘅速度（提示話向上為正） | m s⁻¹ |
| v 合速率 | 應該係vₓ、vᵧ加埋嘅實際速度 | m s⁻¹ |
| a 加速度（垂直） | 得個垂直方向嘅加速度，即係地心吸力嘅效果 | m s⁻² |
| Eₖ 動能（質量1kg） | 動能，佢話當個波質量係1kg嚟計 | J |
| y₂ 第二顆球高度 | 應該係第二個波而家嘅高度，但冇對應嘅「x₂距離」，搵極都搵唔到 | m |

## iPad 上的問題
- 最大分別：**電腦版睇唔到嘅「參數／第二顆球／顯示／讀數」成塊panel，去到iPad（768×1024）就完全睇得到**，掣同數字都齊晒，滑桿都掕得郁，冇缺塊。呢點好奇怪：一般會以為闊啲嘅電腦視窗睇到嘅嘢應該多過窄嘅iPad，但呢度啱啱相反。
- 冇見到手指按唔中嘅情況（呢次用滑鼠模擬，冇特登用手指觸控嚟試）。
- 冇見到要橫向scroll嘅地方，成個直度佈局睇落幾work，滑桿、剔選格、落單掣都冇畀寬度切走。
- 動畫停低之後個 `t=` 一樣會自己繼續跳，呢個喺iPad都一樣出現，唔係電腦獨有嘅問題。

## 我卡住的地方（按嚴重程度排）
1. **電腦預設視窗（800×609，未改過大小）下，「參數／第二顆球／顯示（箭嘴剔選）／讀數」成一大撻panel完全睇唔到，淨係一片空白**，無論點scroll都係咁，一路scroll到頁尾都係空白（唯獨最尾有少少內容睇得返）。呢個直接令Task 2（搵最高點速度）喺電腦度完全做唔到，Task 3嘅剔選格都要靠盲搵先撳到。呢個係最嚴重問題。
2. 「跳到 t=」個數字輸入格，直接打字然後撳Enter，結果好唔穩定：有次打「1.00」變咗做0.71，有次仲搞到成個模擬設定（角度、第二個波）都變晒，完全唔知因果關係，用嗰下手足無措。
3. 動畫落地/停低之後，右上角嘅 `t = ... s` 會自己一路跳落去（例如由2.27跳到3.4、5.7秒），但個波完全冇郁，搞到唔知係咪個模擬其實仲喺度計緊嘢，定係壞咗。
4. 3D鏡頭角度太斜，令到已經著地嘅波（尤其飛得遠嗰個）睇落好似仲浮喺半空，好易誤會佢未落地。
5. 讀數panel冇第二個波嘅水平距離數值（x₂），淨係得高度（y₂），想同時比較兩球飛幾遠冇辦法直接讀到準確數字，要用肉眼喺個俯視細圖度估。
6. 「還原預設」撳完出嚟嘅畫面，有時同開場嗰個唔一樣（一次見到扁平嘅單一軌跡），唔知邊個先係真正「預設」，用起上嚟好confusing。
7. 「顯示」嗰堆剔選格（v、vₓ、vᵧ、a、W……）冇逐個試，因為3D畫面已經同時出現好多條綠色箭嘴，好難憑肉眼分邊條箭嘴對應邊個剔選格。

## console 錯誤

```
[warn] THREE.Clock: This module has been deprecated. Please use THREE.Timer instead.
[info] Download the React DevTools for a better development experience...
[debug] [vite] connecting... / connected. / hot updated: /src/index.css
```
呢啲都唔係紅色錯誤，得一個黃色warning（THREE.Clock deprecated），對用戶操作睇落冇影響。
