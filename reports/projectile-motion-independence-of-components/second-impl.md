# 第二實作比對：projectile-motion-independence-of-components（閘 2 第 4 輪，主實作 v0.3.0）

積分方法：**本輪不做數值積分，全部用閉式解。** 無空氣阻力 → 規格方程（x = u cosθ·t，y = h + u sinθ·t − ½gt²，v_y = u sinθ − gt），落地時刻用二次方程精確解；有空氣阻力（線性，a = −(k/m) v）→ 指數解 v_x = u cosθ e^(−ct)、v_y = (u sinθ + g/c) e^(−ct) − g/c、x = (u cosθ/c)(1 − e^(−ct))、y = h + ((u sinθ + g/c)/c)(1 − e^(−ct)) − (g/c)t，c = k/m，1 − e^(−ct) 用 expm1 計算；落地時刻在 [t_n, t_{n+1}] 內對閉式 y(t) 做 100 次二分求根（達機器精度）。每幀直接在 t = n·dt 代入。
步長：dt = 0.001 s（取自 index.json）。幀數：4000（t = 0 至 3.999 s；落地後 t 凍結）。
本輪模型改動（依派工說明）：阻力 F = −k v、k = 0.3 N s m⁻¹、對兩顆球都作用；新增 m（kg）、Ek = ½mv²、EkB = ½mv_B²；companion 預設 none。其餘定義同前（obs key、y ≤ 0 落地步內插值、全部落地後整個狀態含 t 凍結、h = 0 且 θ ≤ 0 起始在地面、θ < 0 時 H = h）。
因為有阻力也有解析解，**11 個運行全部用 1e-6 容限**（不再用 1e-4 的數值對數值容限）。

## 結論

**一致。** 11 個運行、150 個（運行 × key，含 frame.t）組合全部通過 1e-6 容限；7 個落地運行的落地幀索引完全相同，落地 t 差 ≤ 3.3e-13 s；凍結行為兩者相同。

- 無空氣阻力 7 個運行：最大絕對誤差 2.8e-10（random-4 的 EkB，m = 4.91、量值約 2000 J，相對 3.2e-14），其餘 ≤ 1e-11。
- 有空氣阻力 4 個運行（random-0/1/2/3；m 分別 0.157、1.056、1.404、4.685）：x、y、vx、vy、ax、ay、Ek、xB、yB、EkB 與線性阻力解析解的差 ≤ 1.1e-11（random-2 的 EkB，量值約 1700 J），其餘 ≤ 8.4e-13。**主實作有阻力時的輸出與解析解一致到浮點精度**，即主實作不是用有限步長積分（或積分後結果與解析解無可辨差異）；random-2（θ = −12°、h = 17、u = 49）在第 1174 幀、t = 1.173334 s 落地，兩者 t 差 1.8e-14。
- 新參數 m：無阻力運行 random-4（m = 4.913）路徑與規格方程一致到 2.8e-12（x），Ek 與 ½mv² 逐幀差 0；有阻力運行 ax、ay 與 −(k/m)v_x、−g − (k/m)v_y 逐幀殘差 ≤ 1.8e-15，t = 0 時 Ek = ½mu² 殘差 ≤ 2.3e-13。
- companion = drop 且有阻力、θ > 0、h > 0（random-3，g = 1.6）：B 球 yB、EkB 與「u = 0 的線性阻力閉式解」一致到 1.1e-11，證明阻力確實對 B 球作用；B 在 4 s 內未落地（yB(3.999) = 0.158 m，無阻力自由落體需 3.86 s，有阻力更慢），此運行未能覆蓋「B 先落地、主球後落地」的個別凍結分支（第二實作自測見「額外檢查」）。
- 頂層 frame.t、obs.t、obs.tf 三者全程相同；7 個落地運行凍結後 t 與全部 obs key 漂移恰為 0。

## 不一致的判斷

無不一致。為確保「一致」不是「同時錯」，以下用規格解析解與極限情況獨立驗證（直接檢查主實作 data/*.json，不經第二實作；並另以獨立 RK4 核對第二實作自己的閉式解代數）：

1. **第二實作閉式解的自我核對**：對 random-0/1/2/3 的參數，用 dt/10 的 RK4 直接積分 a = −(k/m)v − g ŷ 至 T = 0.5、1、2 s，與閉式解 x、y、v_x、v_y 差 ≤ 6.7e-13。閉式解代數正確；因此上表的誤差就是主實作與線性阻力解析解的差。
2. **主實作有阻力數據的內部一致性**（4 個運行，全程飛行幀）：
   - 每幀 (ax, ay) 與 (−(k/m)v_x, −g − (k/m)v_y) 殘差 ≤ 1.8e-15（k = 0.3，m 取各運行的值）。t = 0 幀 ax = −(k/m) u cosθ、ay = −g − (k/m) u sinθ 殘差 ≤ 2.3e-13。
   - 機械能 Ek + m g y 單調遞減；中央差分 dE/dt 與 −k v² 的殘差 ≤ 6.4e-5（random-0，c = 1.92 s⁻¹；為差分截斷誤差量級，相對 k v² 約 1e-5），random-3（c = 0.064）為 7.0e-7。功率關係 P = F·v = −k v² 成立。
   - companion = fast（random-0/1/2）：yB − y 恰為 0、xB − 2x 恰為 0。線性阻力下 x、y 方程解耦、x 方程對 u cosθ 線性，所以「水平初速加倍」的球仍與主球垂直同步、水平位移恰為兩倍——這是線性阻力特有的性質（二次阻力不成立），主實作數據呈現此性質，是阻力形式確為線性的獨立證據。
   - companion = drop（random-3）：xB 恆 0；yB、EkB 與 u = 0 的閉式解差 ≤ 1.1e-11，即 B 球也受阻力。第 1 幀 yB 下降 8.0e-7 = ½g dt²、EkB = 6.0e-6 = ½m(g dt)²，符合靜止起步時阻力為零。
   - 終端速率：random-0（m = 0.157，v_t = mg/k = 5.120 m s⁻¹，c = 1.92 s⁻¹）t = 3.999 s 時 v_y = −5.115049，閉式解 −5.115049，v_x = 9.2e-4 → 0；差 v_t 的 5e-3 正是 (u sinθ + v_t) e^(−ct) 的餘項。
3. **無阻力運行 vs 規格解析解**：第二實作直接代入規格方程，上表誤差即主實作與解析解的差（≤ 2.8e-10，皆為量值 ~10³ 的 Ek 相對 1e-13）。v_x 全程與 v_x(0) 差 0（規格容許 1e-6）；Ek + m g y 守恆漂移 ≤ 2.3e-10；Ek 與 ½mv² 逐幀差 0（含 m = 4.913 的 random-4）。
4. **規格驗證條件**（主實作數據）：default 落地 v − u = 0；上升時間 0.983（幀解析度）對 tf/2 = 0.9829；最高點 Ek − ½mv_x² ≤ 1.9e-6、H − y ≤ 1.9e-7（在 ½g(dt/2)² ≈ 1.2e-6 的幀解析度內）。
5. **落地時刻**：7 個落地運行落地幀索引相同、t 差 ≤ 2e-13；有阻力的 random-2 也如此，表示主實作落地的步內插值在有阻力時同樣求到解析根（若用線性插值，t 差會在 1e-8 量級，x 差在 1e-6 量級，仍可通過但不會是 1e-14）。

## 額外檢查

### 量綱
- 規格方程：x = u cosθ·t（m s⁻¹·s = m）；y 三項 m、m s⁻¹·s、m s⁻²·s² 皆為 m；v_y m s⁻¹；H = h + u² sin²θ/2g：m + (m² s⁻²)/(m s⁻²) = m。
- 線性阻力：[k] = N s m⁻¹ = kg s⁻¹；c = k/m 為 s⁻¹（k = 0.3、m = 1 → 0.3 s⁻¹；m = 0.1 → 3 s⁻¹）；a = −c v 為 s⁻¹·m s⁻¹ = m s⁻² ✓；終端速率 mg/k = kg·m s⁻² / (kg s⁻¹) = m s⁻¹ ✓（m = 1 → 32.7 m s⁻¹；m = 0.1 → 3.27 m s⁻¹；m = 5 → 163.5 m s⁻¹）。
- 閉式解：x = (u cosθ/c)(1 − e^(−ct))：m s⁻¹ / s⁻¹ = m ✓；y 的 (g/c) t：m s⁻²/s⁻¹·s = m ✓；((u sinθ + g/c)/c)：m s⁻¹/s⁻¹ = m ✓。
- Ek = ½mv²：kg·m² s⁻² = J；random-4 t = 0 Ek = ½·4.913·26.09² = 1672 J（主實作數據相同）；scenario-same-landing 落地 EkB = m g h = 196.2 J。
- 角度：controls 以度輸入，兩實作內部用弧度；時間：凍結後 t 的單位與值都不變，tf ≡ t 全程成立。

### 對稱
- 無阻力：R(20°) − R(70°) = −1.8e-15，R(30°) − R(60°) = −3.6e-15；R(44°、45°、46°) = 22.9218、22.9358、22.9218，45° 最大且鏡像相等。上升／下降時間相等、落地速率 = 初速（見上）。
- 有阻力（m = 1、k = 0.3）對稱**應該**破壞，且確實破壞：最佳角 40°（R = 16.007 m）< 45°（R = 15.774 m）；R(30°) − R(60°) = +2.36 m（低角較遠）；default 參數 t_top = 0.861 s、tf = 1.804 s，下降比上升多 0.082 s；落地速率 10.47 < u = 15。方向全部符合物理預期。
- 線性阻力下「fast」球仍 yB ≡ y、xB ≡ 2x（第二實作自測差 0；主實作數據亦差 0），drop 球 xB ≡ 0。

### 極限
- **t = 0**：所有 11 個運行 t = 0 幀殘差 ≤ 2.3e-13（x = 0、y = h、v = u 分量、a 含阻力起始值、Ek = ½mu²、t = tf = 0）。
- **m 不影響無阻力路徑**：第二實作 m = 0.1、1、5 的 x、y、t 逐幀位元級相同（差 0），Ek 按 m 比例縮放（差 1.7e-13），tf 相同。主實作方面，random-4（m = 4.913）與規格方程一致到 2.8e-12，等價於證明主實作無阻力路徑不含 m。
- **m 影響有阻力路徑**：u = 15、θ = 40° 射程 m = 0.1：3.75 m；m = 1：16.01 m；m = 5：20.93 m；無阻力 22.59 m。重球趨近無阻力值，方向正確。
- **k/m 很大 → 終端速率 mg/k**（u = 1、θ = −30°、h = 50）：m = 0.1、k = 0.3（c = 3 s⁻¹）在 t = 3.999 s 時 v = 3.269983，mg/k = 3.270000，差 1.7e-5 = 餘項 e^(−12) 量級，a_y = −5e-5 → 0，x = 0.288673 → u cosθ/c = 0.288675。c = 30 s⁻¹（m = 0.1、k = 3 或 m = 1、k = 30）：v = 0.327000 = mg/k 差 5.6e-17，a_y = 1.8e-15，x = 0.028868 = u cosθ/c；後兩組結果位元級相同，證明模型只透過 k/m 依賴 k 與 m（Ek 除外）。
- **u = 50、θ = 90°、m = 0.1**（u ≫ v_t = 3.27）：最高點 t = 0.930 s（解析 ln(1 + u/v_t)/c = 0.9302）、y = 13.62 m（解析 13.62）；x 全程 ≤ 1e-15；4 s 內未落地，v(3.999) = 3.2697 → v_t。
- **k → 0**（m = 1）：k = 1e-2、1e-4、1e-6 時與規格方程最大差 2.2e-1、2.2e-3、2.2e-5，與 k 成正比，收斂到規格方程；tf 差 −6.4e-3、−6.4e-5、−6.4e-7。
- **θ = 0、h = 0**：一開始在地面，t = tf = 0、全部為 0、立即凍結。θ = −30°、h = 0、drop、有阻力：主球與 B 皆在地面。h = 0、θ = 40°、drop：主球正常飛行，B 自第一幀 yB = 0、EkB = 0。
- **drop、θ = 30°、h = 20、有阻力**（index.json 無此組合，第二實作自測）：B 在第 2246 幀落地（t ≈ 2.246 s，比無阻力 √(2h/g) = 2.019 s 慢），落地後 yB、EkB 個別凍結，t 繼續前進至主球落地 3.0857 s 才整體凍結。此「B 先落地」分支本輪仍未經兩實作比對（random-3 的 B 在 4 s 內未落地）。
- **g 增大 → 飛行時間縮短**：g = 9.81 落地 1.9657 s = 2u sinθ/g；g = 1.6 解析 12.05 s，4 s 內未落地。

## 規格待釐清

1. **空氣阻力形式已由老師定為線性 F = −k v、k = 0.3 N s m⁻¹**（規格文件本身仍只寫「開／關」，建議把形式與 k 值補入規格）。線性阻力的教學含意：終端速率 mg/k 與 m 成正比（m = 0.1 kg 時只有 3.3 m s⁻¹，u 下限 1 m s⁻¹ 以外的任何發射都在起始即遠超終端速率，球會在 1 s 內幾乎失去全部初速；m = 5 kg 時 163 m s⁻¹，阻力幾乎看不出）。若老師希望「開阻力」在預設 m = 1、u = 15 時有可見但不誇張的效果，現值（射程 22.6 → 16.0 m）合適；但 m 滑桿兩端的觀感差異很大，介面上可考慮顯示 mg/k。
2. **m 的角色**：規格參數表沒有 m。無阻力時 m 只影響 Ek 讀數（路徑不變，這本身是有教學價值的現象：「重球不會飛得較遠」）；有阻力時 m 才影響路徑。建議在指南或面板註明，免得學生把「調 m 路徑不變」當成 bug。
3. **tf 的定義與凍結時刻**（前兩輪已提）：兩實作都令 tf ≡ t 並凍結在最後一顆球落地；drop、θ > 0、h > 0 時 B 先落地、主球後落地的分歧情況，index.json 至今沒有一個運行在 4 s 內覆蓋（random-3 的 B 在 3.999 s 時離地 0.158 m）。建議下輪固定加一個 drop、θ = 30°、h = 20、無阻力的運行（B 在 2.019 s 落地、主球 2.924 s）。
4. **H 在有阻力時的定義**：兩實作都用規格公式 H = h + u² sin²θ/2g（無阻力最高點）。有阻力時實際最高點較低（u = 50、θ = 90°、m = 0.1：實際 13.6 m 對公式 127 m），若面板在開阻力時仍顯示這個 H，會與畫面矛盾；建議開阻力時隱藏 H 或改標「無阻力時的最高點」。
5. **H 在 θ < 0 時 = h**（前輪已提）：規格公式對 θ < 0 給出大於 h 的值，兩實作都改為 H = h。
6. **落地後的狀態**、**h = 0 且 θ ≤ 0 起始在地面**、**「水平初速加倍」**：同前輪，兩實作一致，規格未寫。
7. **非 observe 輸出的提醒**（同前輪）：data 檔 `meta.tf`（random-0 = 5.859、random-3 = 22.57）不是 obs.tf，也不等於無阻力解析飛行時間（random-0 為 3.71 s）或有阻力落地時刻；不在比對範圍，只提醒介面不要把它當飛行時間顯示。
