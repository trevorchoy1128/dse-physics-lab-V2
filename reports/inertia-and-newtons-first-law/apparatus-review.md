## 結論
**可接受。**

第 5 輪唯一必改已解決：標牌固定在泳道左端後，整個推力階段「方塊 A　0.200 kg（琥珀色）」「方塊 B　1 kg（鋼藍色）」與「F 手 → 方塊」相距數百像素，放手後與 R 標籤也分開。第 5 輪後的四項改動沒有帶來新的相撞：衝量條加高後「J = … N s」在條內清楚，三個速率（5、10、1.0 m s⁻¹）的條長差別一眼看得出；guide 步驟 4 改為先設 μ₂ = 0，與 8-early／8-end／extra-two-blocks-released 的畫面（μ₂ 滑桿 = 0、放手後兩線各自水平）對得上。新截圖 extra-bus-start-mu04 的受力（f 向前、淨力向前、兩支等長 180 N、s_rel = 0.00 m、乘客與巴士 v–t 重合）正是 §8 第 8 條「μ ≥ a/g 一起走」的畫面。餘下的全是文字貼邊、被桌腳穿過、圖例首字被軸遮之類的小事，字都讀得出，不會令學生誤會器材或受力；列在建議，不擋簽收。

## 擺法與接法

- **情景 1（單方塊）**：方塊在 A（s = 0）起步，A–B 0.75 m 光滑、B 之後粗糙；手在左、推力向右；R 由接觸面向上、W 由接觸點向下、f 貼方塊底。extra-release-smooth-2forces（μ₁ = μ₂ = 0，t = 0.642 s 放手，t = 1.31 s）：手消失、只剩 R 與 W、綠色速度箭嘴仍在、「2 支（水平 0 支）淨力 = 0 N」——2024 卷一乙部 Q3(b) 的正確受力圖。extra-release-moving（t = 0.600 s 放手，t = 1.20 s 已過 B）：橙色摩擦向後、黑色淨力向後等長、「3 支（水平 1 支）淨力 = −0.392 N」。extra-release-stopped（t = 1.27 s 在粗糙段放手，t = 3.83 s）：停在 1.62 m、摩擦與速度箭嘴消失、「2 支」；由 B 過後的速度算，停車距離與 v²/(2μg) 相符。4-end（F = μ₂mg = 1 N，g = 10）：紫、橙等長反向、無淨力箭嘴、v 恆定。2-end（F = 0.3 N < μ₂mg，停下）：紫、橙等長反向、淨力 0 N、「4 支（水平 2 支）」——靜止時摩擦 = −F 的正確畫面。5-early／5-end（靜止放手，μ = 0.2）：只有 R、W 兩支。全部對。
- **情景 1（雙方塊）**：上下兩張桌各自鏡頭；8-early 兩隻手同一推力 1 N、μ₁ = μ₂ = 0；8-end t = 12 s 兩塊仍在加速、v–t 兩條斜線（A 陡、B 平）；extra-two-blocks-released 放手後兩線各自水平、A 比 B 快。擺法對，標牌現在不擋任何標籤。
- **情景 2（桌布）**：抽出前布在桌面板上、樽在布上、布尾在樽左 0.4 m、手在布右端；摩擦向右、淨力向右等長（cloth-t0 淨力 1.47 N = μ布mg）。抽出後樽在桌面滑行、只剩 R 與 W、標籤由「R 布 → 樽」改為「R 桌 → 樽」（10-early、v10）；v布 = 10 時 Δv 減半、條長減半；v1-stuck 樽隨布走、條近滿格、紅字「樽追上布速，隨布一起走：桌布抽不出」。對。
- **情景 3（巴士）**：只有地面視角、無虛擬力。起步 μ = 0（6-early）：乘客身上只有 R、W，淨力 0 N，s_rel 變負。起步 μ = 0.2 < a/g（7-early、bus-start）：f 向前、淨力向前等長（118 N）、「乘客相對地板滑動（地板加速超過 μg）」、s_rel 負值。**起步 μ = 0.4 ≥ a/g（新截圖 bus-start-mu04）**：f 向前、淨力向前、兩支等長（180 N = 60 kg × 3 m s⁻²）、s_rel = 0.00 m、沒有「相對地板滑動」那一行、v–t 只見一條線——§8 第 8 條「一起走」的正確畫面。急煞（bus-brake）：只有向後的橙、黑兩支，速度箭嘴向前，v–t 兩線分開。握扶手（bus-brake-handrail）：紫色扶手力由手部沿橫桿向後、s_rel = 0、乘客 v–t 與巴士重合。乘客身上從沒出現向前（急煞）或向後（起步）的箭嘴。對。
- **情景 4（太空）**：無重量、無摩擦；引擎開時火焰在推力反方向、關時無火焰、三艘各自保持原速（3-end、engine-off 的 v–t 三條水平線）；船頭固定。對（火焰位置見不確定 1）。

## 理想化假設的表達

- 畫面底部常設假設一行（方塊、物件、乘客視為質點；μs = μk = μ；桌布恆速抽出；車廂無限長、不模擬撞牆；向右為正）——有。
- 「桌布以恆定速率抽出」：拉布的手＋「v布 = … m s⁻¹（恆速）」——有。
- 「車廂視為無限長」：車身貫穿畫面＋標籤——有。
- 「光滑」（μ = 0）：淺灰＋「光滑」字樣；μ > 0 斜線陰影＋「μ = …」——有。
- 「地面（慣性）視角；考試作答一律用地面視角」：情景 3 左上常設；起步且滑動時加「乘客相對地板滑動（地板加速超過 μg）」，不滑（mu04）或 μ = 0 時該行不出現——有，而且跟着條件變。
- 「太空：無重量、無摩擦；關引擎後沒有任何力（船頭方向與速度方向無關）」——有。
- 「箭嘴已按邊緣空間同步縮短（比例不變）」：1-end、11-end 有；「鏡頭跟着物體移動（比例不變）」：desktop、2-end、4-end、6-end、7-end、8-end、9-end、v1-stuck、bus-brake 有。
- 「只看淨力：個別力已隱藏」：extra-net-only 紅字、一支箭嘴都沒有——有。
- 衝量條「滿格 = 臨界速度 √(2μ布gL) 時的衝量 1.08 N s」——改寫後明確是衝量並交代來源——有。

## 建議修改（按嚴重程度排）

沒有必改項目。以下全是小事，改不改都可簽收；若還有一次順手修改的機會，按次序：

1. **小事：桌腳畫在軸標題上層。** 白底框加了之後桌腳仍在文字上面（desktop 打開時的預設畫面就是）。把桌腳的繪畫層放到文字下層，或標題改放刻度帶內（與刻度數字同一行、靠右）就徹底解決。
2. **小事：雙方塊下方泳道。** W 標籤壓桌面板上緣；補「方塊 A 的桌」；上方泳道補一行軸標題並讓左端刻度數字避開桌腳。
3. **小事：衝量條近滿格時「N s」溢出條框**（v1-stuck）。文字改為靠條內右端對齊、超過條長時貼右緣往左寫即可。

## 我不確定、想問老師的

1. **向左那艘船的火焰位置**（第 4、5 輪未變，開發端交老師定）：船頭固定向左，引擎「向前」（+x）時火焰從船頭那端噴出。物理上噴口與推力反向是對的，畫面也註明「船頭方向與速度方向無關」；但學生可能問「為何火從船頭出」。(a) 保持現狀；(b) 引擎方向改為相對船頭。

## 六輪總結

**器材與擺法最終狀態。** 四個情景的示範物全部認得出是課本圖 3.2d／3.2e 及實驗 3a 的東西：桌（桌面板、桌腳、光滑段與粗糙段、A、B 標記、刻度帶）、方塊（琥珀 A、鋼藍 B，各有固定標牌）、推手（放手即消失）、桌布（鋪在桌面板上、樽在布上、手在布尾、「恆速」標示）、樽（有頸有蓋）、車廂（貫穿畫面、窗、吊桿、扶手、車輪、地板線）、乘客（圓頭長方身、腳貼地板）、三艘飛船（船頭固定、火焰只在引擎開時出現）。受力箭嘴的出發點、顏色（重量紅、法向反作用力藍、摩擦橙、施力紫、淨力黑、速度綠、加速度綠虛線）、「施力物 → 受力物」標籤格式六輪來一直對。歷輪改動按 fix-log：第 1 輪把推手畫成手、桌畫成桌、樽加頸、車廂截斷、水平／垂直力各一像素比例；第 2 輪鏡頭跟乘客、車廂貫穿畫面、桌布 μ 顯示修正、施力物改「布」；第 3 輪標籤白底框與位置規則、分段標籤移到地板上、衝量條固定尺 m√(2μ布gL)；第 4 輪淨力標籤避讓摩擦、速度箭嘴避讓 R、方塊標牌、衝量條加闊；第 5 輪標牌固定左端、軸標題白底框、衝量條加高並在條內寫數值。到 0.2.4，雙方塊模式整個推力階段與放手後都沒有相撞；桌布三個速率的差別一眼看得出、讀得出；巴士六張截圖（μ = 0、0.2、0.4 起步；急煞；握扶手；巴士停）覆蓋 §8 第 7、8 條全部分支。理想化假設全部有畫面或文字表達，且巴士的「相對地板滑動」一行會跟條件變。
