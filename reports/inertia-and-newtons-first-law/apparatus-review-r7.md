## 結論
**需修改**：必改 1、2、3。

- **μ 檢查通過。** 40 張截圖逐張看過，沒有「μ」、「摩擦係數」、「μs」、「μk」。桌面分段標籤已是「A–B 光滑」／「A–B 摩擦力 f₁ = 0.400」／「B 之後摩擦力 f₂ = 0.400 N」／「B 之後光滑」；桌布是「布對樽的摩擦力 f布 = 1.5 N」「桌面摩擦力 f桌 = 2 N」「滿格 = 剛好抽不出時的衝量 1.1 N s」；巴士是「巴士加速度超過摩擦力能給乘客的 f/m = 2 m s⁻²」；假設行寫「靜摩擦上限等於滑動時的摩擦力（同一個 f）」；四個滑桿標題全是「摩擦力（滑動時的大小）/ N」。
- **必改 1（新標籤相撞）**：前後兩段都粗糙時（scenario-5 預設 f₁ = f₂ = 0.4），「A–B 摩擦力 f₁ = 0.400 N」錨在 A、長約 150 px，而 A–B 只有 0.75 m ≈ 118 px，尾端被錨在 B 的第二個標籤的白底框蓋住，畫面讀成「A–B 摩擦力 f₁ = 0.400 B 之後摩擦力 f₂ = 0.400 N」——f₁ 沒有單位、兩句連成一句。舊寫法「μ₁ = 0.200」短，沒撞；改成摩擦力後字長了就撞了。
- **必改 2（三艘飛船位置）**：「三艘飛船」模式下，藍船與灰船不是畫在各自的真實位置。extra-space-engine-off（t = 1.73 s，主船 s = 2.54 m）：藍船應在 6.0 m、灰船在 −0.9 m，三艘卻並排在主船旁；scenario-3-end（t = 12 s，主船 s = 0）：藍船應在 +24 m、灰船在 −24 m，藍船仍在 s = 0 的位置、灰船只左移約 1 m；scenario-9-end 三艘全在 s = 144 m 的同一格，v–t 卻是 22、24、26 m s⁻¹ 三條線。M8 要學生在同一畫面見到「靜者恆靜、動者恆動」，現在畫面是三艘船編隊不動，只有箭嘴和線圖在變，還與下方刻度矛盾。沒有像巴士那樣的「◀ 在 s = … m」邊緣標記。
- **必改 3（假設文字過時）**：假設行仍寫「車廂視為無限長，不模擬撞牆」，但 0.3.0 已把車廂改為 18 m 有頭有尾。scenario-7（f = 0，「巴士起步時乘客被拋向後」預設）走到底：s_rel = −73.3 m，乘客站在馬路上、樹在兩旁、巴士在畫面外（「巴士中心在 s = 73.3 m ▶」），力標籤仍是「R 地板 → 乘客」。文字說車廂無限長，畫面說車廂 18 m 而乘客已經在車外——兩者不能同時成立。

其餘 0.3.0 新畫面（三張線圖、a–t 圖兩條線、紅旗與紅色 s_rel 標示線、扶手、火箭造型）都合理，見逐件表。上輪八項小事有七項未動、一項（9-end 的「v」被註記蓋住）因火箭移到左方而自然消失。

## 擺法與接法

- **情景 1（單方塊）**：方塊在 A（s = 0）起步、A–B 0.75 m、B 之後粗糙；手在左、推力向右；R 由接觸面向上、W 向下、f 貼底。release-smooth-2forces（f₁ = f₂ = 0，t = 0.641 s 放手，t = 1.31 s）：無手、只剩 R 與 W、綠色速度箭嘴仍在、「2 支（水平 0 支）淨力 = 0 N」——2024 卷一乙部 Q3(b) 的正確受力圖。release-moving（t = 0.616 s 放手，t = 1.17 s 剛過 B）：橙色摩擦向後、黑色淨力向後等長、「3 支（水平 1 支）淨力 = −0.400 N」。release-stopped（t = 1.24 s 放手，t = 3.81 s）：停在 1.58 m、摩擦與速度箭嘴消失、「2 支」。4-end（F = f₂ = 1 N，g = 10）：紫、橙等長反向、淨力 0 N、v–t 水平 2 m s⁻¹。2-end（F = 0.3 N < f₂ = 0.4 N，t = 4 s 停下）：紫、橙等長反向、淨力 0 N、「4 支（水平 2 支）」——靜止時摩擦 = −F。5-early／5-end（靜止放手，f₁ = f₂ = 0.4）：只有 R、W。全部對。
- **情景 1（雙方塊）**：兩張桌各自鏡頭；8-early 兩隻手同一推力 1 N；8-end t = 12 s 兩塊仍在加速、v–t 兩條斜線（A 陡 B 平）、a–t 兩條水平線（5 與 1）；two-blocks-released 放手後兩線各自水平。對。
- **情景 2（桌布）**：抽出前布在桌面板上、樽在布上、布尾在樽左 0.4 m、手在布右端「v布 = 5 m s⁻¹（恆速）」；摩擦向右、淨力向右等長 1.5 N（cloth-t0）。抽出後標籤由「R 布 → 樽」改「R 桌 → 樽」（10-early、v10）；v布 = 10 時 Δv 減半、條長減半；v1-stuck 樽隨布走、條近滿格、紅字「樽追上布速，隨布一起走：桌布抽不出」。對。
- **情景 3（巴士）**：只有地面視角、無虛擬力。起步 f = 0（7-early）：乘客只有 R、W，淨力 0 N，s_rel 變負。起步 f = 120 N < ma（6-early、bus-start）：f 向前、淨力向前等長 120 N、「乘客相對地板滑動（巴士加速度超過摩擦力能給乘客的 f/m = 2 m s⁻²）」。起步 f = 240 N ≥ ma（bus-start-f240）：f 向前、淨力 180 N、s_rel = 0.00 m、無滑動提示、v–t 一條線——§8 第 8 條「一起走」。急煞（bus-brake，t = 8.5 s）：只有向後的橙、黑兩支，速度箭嘴向前，v–t 兩線分開，乘客在車尾附近（s_rel = −7.65 m 仍在 18 m 車廂內）。握扶手（bus-brake-handrail）：紫色扶手力沿橫桿向後、s_rel = 0。乘客身上從沒出現向前（急煞）或向後（起步）的箭嘴。對。**但** f = 0 走到底乘客在車外，見必改 3。
- **情景 4（太空）**：無重量、無摩擦；引擎開時火焰在推力反方向、關時無火焰；主船 s 讀數與刻度一致（engine-on s = 1.05 m、engine-off s = 2.54 m、9-end s = 144 m）。**三艘模式下另外兩艘的位置不對**，見必改 2。

## 理想化假設的表達

- 畫面底部假設行：「方塊、物件、乘客視為質點，不模擬傾倒；靜摩擦上限等於滑動時的摩擦力（同一個 f）；桌布以恆定速率抽出；車廂視為無限長，不模擬撞牆；向右為正方向」——有，**但「車廂視為無限長」已與 18 m 車廂不符**（必改 3）。
- 「桌布以恆定速率抽出」：拉布的手＋「v布 = … m s⁻¹（恆速）」；a–t 圖例「藍＝桌布（恆速，a = 0）」——有。
- 「光滑」（f = 0）：淺灰＋「光滑」字樣；f > 0 斜線紋＋「摩擦力 f = … N」，紋密度跟 f——有。
- 「地面（慣性）視角；考試作答一律用地面視角」：情景 3 左上常設；起步且滑動時加「乘客相對地板滑動（…f/m = … m s⁻²）」，不滑（f240）或已停時該行不出現——有。

## 建議修改（按嚴重程度排）

1. **必改：兩段都粗糙時分段標籤相撞。** 「A–B 摩擦力 f₁ = 0.400 N」錨在 A、比 A–B 段長，尾端被 B 標籤的白底框蓋住，讀成「f₁ = 0.400 B 之後摩擦力 f₂ = 0.400 N」（5-early、5-end）。改法任一：(a) A–B 標籤右端對齊 B、超長時縮寫成「A–B f₁ = 0.400 N」；(b) 兩段標籤分兩行，A–B 在上、B 之後在下；(c) 合成一行「A–B f₁ = 0.400 N ｜ B 之後 f₂ = 0.400 N」錨在 A。順手把桌腳的繪畫層放到文字下層（上輪小事 1），因為現在桌腳穿的是數字（desktop、ipad-landscape、release-stopped）。
2. **必改：三艘飛船要畫在真實位置。** 以主船鏡頭為準，藍船畫在 s_藍、灰船畫在 s_灰；離開 24 m 視野時用本模擬已有的邊緣標記寫「藍船在 s = 168 m ▶」「◀ 灰船在 s = 120 m」（9-end 的數字），像「巴士中心在 s = 73.3 m ▶」那樣。這樣 3-early → 3-end 學生會見到藍船向右飛走、灰船向左飛走、琥珀船不動——才是 M8。若開發端堅持三艘各自鏡頭，畫面必須像雙方塊那樣寫明「各自鏡頭跟隨」並各自給刻度，但這會失去相對運動的畫面，不建議。
3. **必改：假設行「車廂視為無限長，不模擬撞牆」要改。** 車廂已是 18 m。建議改為「車廂長 18 m；乘客滑出車廂後不模擬撞牆或跌落，仍視為站在地面上」；並在乘客在車外（|s_rel| > 9 m）時把「R 地板 → 乘客」改為「R 地面 → 乘客」。若老師寧願不讓乘客離開車廂，另一做法是 f = 0 的預設把巴士加速度或巡航時間調小，令 |s_rel| 不超過 9 m——但那要改 §5 的預設，須老師定。
