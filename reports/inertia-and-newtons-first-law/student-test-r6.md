# 學生試用：http://localhost:4174/#/sim/inertia-and-newtons-first-law
裝置：電腦（先做）／iPad 直向（768×1024，重做第2件事）

## 第一眼
未撳任何嘢之前，個畫面已經有兩條桌，上面各有一個方塊、周圍成堆箭嘴（藍色、紫色、紅色、黑色），右手邊一大堆滑桿同數字，最頂有「施力中／已放手」兩粒橙白掣。老師話「開完先按暫停再按還原預設」，但我望住個「▶ 播放」掣寫住「播放」唔係「暫停」，即係話個模擬本身已經係停緊、t=0.00s，冇自動播緊。

比較奇怪嘅係：一打開個畫面已經係「開咗第二個方塊」個狀態（兩條桌、兩個方塊同時出現），唔係得返一個方塊。我第一次見完全唔知邊個先係「正常/預設」畫面，仲以為第二個方塊係一開始就一定有嘅。撳咗「還原預設」之後先變返得一個方塊，先啱返老師之後畀嘅步驟講法。

我淨係睇個標題「慣性與牛頓運動第一定律」先知呢個係力學堂嘅嘢，但唔知第一步應該撳邊度 —— 「步驟」呢個分頁一開始睇唔到，要捲落先見到，如果唔係老師話咗要撳「步驟」，我自己一個未必會諗到撳嗰度。

## 老師叫我做的事

### 1. 兩個方塊：後段摩擦=0、開第二個方塊、放手
步驟：撳「步驟」tab讀第4步 → 將「後段桌面（B之後）的摩擦係數」由0.2改做0 → 剔「第二個方塊（同一推力）」 → 用「跳到 t=」打1（因為要準確去到1秒，冇用逐格逐格撳） → 撳「已放手」
期望：應該見到兩個方塊分別有名，睇得出邊個加速快，放手之後速度應該唔再變。
實際：畫面變成兩條桌疊埋一齊，上面條桌個方塊標示「方塊B 1kg」，下面條桌個方塊標示「方塊A 0.200kg」。跳到t=1.00s：方塊A讀數 v=1.50 m/s、a=1.50 m/s²、s=0.750 m；方塊B讀數v_B=0.300 m/s（但係冇畀a_B呢個讀數，冇直接話你知方塊B個加速度）。撳「已放手」之後：F外加水平力由0.3N變0N，淨力=0N，a=0m/s²，但v保持1.50 m/s冇變，v_B都仲係0.300 m/s冇變——即係話兩個方塊放手後速度都各自唔變，同步驟文字寫嘅一樣。畫面上原本紫色施力箭嘴不見咗，「作用於方塊的力」由3支變2支。
邊個加速快：計返數，方塊A（0.2kg）a=1.50 m/s²，方塊B（1kg）自己心算a_B=0.3/1=0.3 m/s²，即係方塊A（輕嗰個）加速快好多。但係畫面本身唔會直接答你「邊個快」，要自己識計先知。
嘗試次數：3次（改摩擦係數1次、跳到t=1一次、撳已放手一次），全部一take成功。
做到／做唔到：做到。

### 2. 桌布實驗：抽出速率 5 / 10 / 1.0
（呢個部分電腦版做一次、iPad再做多一次，結果一樣，寫喺呢度）

步驟：撳情景「桌布實驗」→ v布維持預設5 → 跳到t=1 → 讀畫面頂嘅衝量文字/bar → 改v布做10 → 跳到t=1 → 讀多次 → 改v布做1.0 → 跳到t=2 → 睇發生咩事

實際：
- v布=5，t=1s：畫面頂有句「衝量 J = f·Δt = 0.119 N s」，下面仲有「Δt = 0.0810 s，Δv = 0.119 m s⁻¹」。呢句字外面包住一個白色長方格，入面有條好幼嘅橙色bar，填咗大概一成（10%）左右（喺desktop個bar太幼，我一開始完全冇為意佢係一條「進度條」，仲以為淨係得文字，後尾去到iPad個bar睇得清楚啲先肯定佢真係有填色）。
- v布=10，t=1s：J=0.0590 N s，Δt=0.0401 s，個bar填得仲少（大概5%），即係抽得快，摩擦作用時間短咗、衝量細咗。
- v布=1.0，t=2s：J=1.00 N s，Δt=0.680 s，個bar差唔多填晒成條（快滿）。畫面出現文字「樽跟上布速，隨布一起走：桌布抽不出」——即係抽得太慢嘅話，個樽會黐住塊布一齊畀拖走，同原本諗嘅「布一下子抽出、樽企定唔郁」個效果完全唔同。v-t圖見到個樽一直加速最後同塊布一樣速度（1 m/s）。
嘗試次數：3種速率都係一take搞掂（不過每次改完slider個模擬會自動reset翻t=0，要再打多次「跳到t=」先睇到1s／2s嗰刻，冇話明會reset，第一次改完仲以為個timer壞咗）。
做到／做唔到：做到。

### 3. 巴士上的乘客：摩擦係數 0.4 / 0.2
步驟：撳情景「巴士上的乘客」→ 將「乘客（鞋）與地板的摩擦係數」設0.4 → 跳到t=1.5 → 睇左上角s_rel同乘客身上箭嘴 → 改返0.2 → 跳到1.5再睇一次
實際：
- μ=0.4，t=1.5s：s_rel = 0.00 m，即係乘客完全冇相對巴士滑動；讀數f=180 N。乘客個藍色人仔身上見到一支黑色「淨力」箭嘴指向右，冇見到獨立嘅「向前箭嘴」——因為根本冇滑動，摩擦已經夠力帶佢一齊加速。
- μ=0.2，t=1.5s：s_rel = -1.17 m（負數，代表乘客相對巴士向後跌咗1.17米），f=118 N（跌到摩擦力上限頂晒籠），畫面文字寫「乘客相對地板滑動」。
嘗試次數：2次設定都一take搞掂。
做到／做唔到：做到。

| F 外加水平力 | 手推嘅力 | 有，N |

## 我卡住的地方（按嚴重程度排）
1. Desktop個「衝量條」太幼太唔顯眼，我一開始完全睇唔到有條bar，仲以為淨係得文字，去到iPad先確定佢真係有填色進度。
2. 一打開個page，個模擬已經自動開咗「第二個方塊」呢個設定（兩條桌、兩個方塊），唔知係咪殘留返舊設定，令我第一眼搞唔清邊個先係「正常」畫面，要撳「還原預設」先返晒去一個方塊。
3. 方塊B（第二個方塊）冇畀a_B（加速度）讀數，淨係得v_B，要老師問「邊個加速快」嗰陣自己計，唔係直接睇得到。
4. 「速度」播放倍率0.1×–2×嗰個下拉揀，撳落去冇見到彈出選單，唔知點揀。
5. g重力加速度個下拉（9.81／9.8／10）喺水平方塊呢個情景，睇唔出揀邊個會令畫面數字有變化，唔明點解要俾我揀。
6. 改完任何一個滑桿（例如摩擦係數、桌布抽出速率），個模擬會自動彈返去t=0，要每次都要再手動打一次「跳到t=」，麻煩且冇提示會reset。
