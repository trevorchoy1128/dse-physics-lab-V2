## 結論
**不通過**（1 項物理：**F1**）。其餘：v0.4 的 *f*/*m* 物理全部通過（129 個運行逐幀誤差 ≤ 1.9 × 10⁻¹³，條件 1–17 通過），滑桿、讀數、圖例、40 張截圖、guide、charts 全無「*μ*」或「摩擦係數」。

- **F1（物理，邊界）：*f*布 = 0 時，靜止的物件在布抽走後被向後移了 2.5 × 10⁻⁵ m。** `audit/r7-data/cloth-f-0.json`（*f*布 = 0、*f*桌 = 2.00 N、*v*布 = 5、*L* = 0.4）：0.080 s 布邊到達物件，*s* = 0、*v* = 0；**0.085 s 起 *s* = −0.0000250 m、滑行距離 `slide` = −0.0000250 m**（= ½ × 2.00 m s⁻² × 0.005²，即模型在 *v* = 0 時仍施加了一步 −*f*桌 的滑動摩擦，然後才判定停止，phase = 3）。物件沒有其他水平力卻自己動，違反第一定律；讀數面板會顯示「位移 −0.0000250 m」「抽出後的滑行距離 −0.0000250 m」（三位有效數字，負號可見）。*f*布 = 0 是滑桿可達的下端（§5：0–3.00 N）。同一運行 *f*布 = 0、*f*桌 = 0（`edge-cloth-f0-fT0`）則 *s* ≡ 0，證明問題出於「離開布時 *v* = 0 卻用了滑動摩擦」。修正方向：離開布或任何 *v* = 0 的瞬間先做靜摩擦判斷（|*F*需| ≤ *f* → 摩擦 = −*F*需、*a* = 0），不要沿用上一步的運動方向。
- **同一根源的記錄（不計入不通過）**：停止瞬間剛好落在幀格時，模型在 *v* = 0 的那一幀仍報滑動摩擦與減速度：`release-1.5-f2-0.4` *t* = 2.125 s（*v* = 0、*f* = −0.40 N、*a* = −2.00 m s⁻²、摩擦箭嘴仍畫），`release-1.5-f2-0.05` *t* = 10.000 s（*v* = 0、*f* = −0.05、*a* = −0.25）；下一幀即 *f* = 0、*a* = 0。而 `extra-release-1s` *t* = 1.750 s 的同類瞬間是乾淨的（*f* = 0、*a* = 0、2 支力）。172 802 幀中只有這 2 幀（`r7-results.json` → `cond.restFrictionInconsistent`）。

## 7. 規格待釐清
1. **條件 1 的 1000 s**：模型時間窗 12 s 後凍結，模擬本身跑不到 1000 s；`model.test.ts` 第 27–28 行亦在凍結時 break，太空以解析式核對。12 s 內 *v* 逐位不變（閉式積分無累積），建議規格改為「時間窗內逐幀 + 閉式解析核對」或明文豁免。
2. **條件 11「任何時刻 \|*a*\| ≤ *f*布/*m*」**：抽出後桌面減速 *f*桌/*m*（預設 2.00）大於 *f*布/*m*（1.50），字面讀法在預設值下即違反（96 幀）；作者與我都按「在布上」讀。v0.3 第 2–6 輪已提，v0.4 文字未改，建議加「在布上」三字。
3. **握扶手且 *m*\|*a*車\| < *f*（§7 扶手力 = *m a*車 − *f*）**：模型在 *a*車 = 1、*f* = 120 時給摩擦 = *ma* = 60 N、扶手力 0（`bus-a1-f120-handrail`：*f* {60, 0, −60}、*F*扶手 {0}）；按規格公式字面應為 *F*扶手 = 60 − 120 = −60 N（扶手向後拉）。模型做法物理合理（扶手只補摩擦不夠的部分），但與公式不同；*m*\|*a*\| ≥ *f* 時兩者一致（±60 N）。請老師確認公式適用範圍。
