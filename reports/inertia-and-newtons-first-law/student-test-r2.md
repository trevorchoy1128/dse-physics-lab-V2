# 學生試用：http://localhost:4174/#/sim/inertia-and-newtons-first-law
裝置：電腦（1440×900，另外都試過 1920×1080）/ iPad 直向（768×1024）

## 第一眼
未撳任何嘢之前，個畫面已經自己喺度播緊（有個方塊喺條桌面度郁緊，落面有兩個圖表）。標題寫「慣性與牛頓運動第一定律」，我估呢個係畀我睇緊「有力推住個方塊」嘅動畫。畫面中間有個提示框寫住 3 點步驟，叫我撳右邊個「已放手」掣，所以第一步應該幾清楚：撳「已放手」。但係我留意到個「知道了」掣（用嚟閂咗個提示框）我試極都撳唔走，成程序個提示框都喺度冇消失過（電腦版）。

另外我第一眼唔知右邊嗰堆滑桿係做咩，例如「μ₁ 前段桌面」「μ₂ 後段桌面」呢啲字我要諗一陣先知道係摩擦力參數，唔係即刻睇得明。

## 老師叫我做嘅事

### 1. 等方塊過咗 B 點先放手，記低放手前後嘅「淨力」「摩擦」「速度」，睇下方塊停唔停
步驟：撳暫停 → 撳「還原預設」（但發覺個掣有時撳咗都冇即時見到重設返 t=0，要撳「暫停」先再撳先得）→ 撳「播放」等方塊行過 B（B 係 0.75 m 嗰度，方塊由 A 開始）→ 撳暫停 → 撳「已放手」。

期望：撳「已放手」嗰一下，速度應該即刻唔變（因為慣性），但摩擦力、淨力嘅讀數應該即刻轉。

實際：
- 放手前（t = 3.98 s，方塊已過 B，仲喺郁緊）：淨力 = −0.0924 N，摩擦 = −0.392 N，速度 = 0.124 m/s，外加力 = 0.300 N
- 撳「已放手」嗰一刻（同一個 t = 3.98 s）：淨力變咗 = −0.392 N，摩擦 = −0.392 N（冇變），速度 = 0.124 m/s（真係即刻冇變，同教學提示講嘅一樣），外加力 = 0.00 N
- 再行多陣（逐格兩下，t = 4.08 s）：淨力 = 0.00 N，速度 = 0.00 m/s，摩擦 = 0.00 N，位移定喺 3.17 m

方塊最後係**停低咗**（唔係一直等速滑落去）。

嘗試次數：呢一步睇落好簡單，但實際撳咗好多次先成功，因為：
1. 第一次撳「已放手」（用滑鼠撳個掣，睇落焦點啱），畫面完全冇反應，掣仲係顯示「施力中」發光；
2. 而且個模擬會喺背景自己越走越快（明明頁面淨係擺喺度冇撳嘢，t 都由幾秒跳到 12 秒），搞到我想「啱啱過 B 就放手」呢個時機好難捕捉到，最後係方塊已經停晒先撳到手。
3. 第二次改用個掣正中間嘅座標先撳中，先至真係轉咗做「已放手」。

**做到**（但過程唔順利，見下面「卡住」部分）。

### 2. 桌布實驗：抽出速率改做 1.0，睇個樽同塊布，再改返做 10，比較 J 同 Δv
先要由「水平桌面上的方塊」轉去「桌布實驗」情景 —— 呢一步先係最大問題（見下面），用滑鼠撳個「桌布實驗」掣完全撳唔郁，撳咗七、八次都係停喺原本嗰個情景，試埋雙擊都係咁。最後係亂咁試鍵盤（撳咗已經 selected 嗰個掣，跟住撳 Tab 再撳 Enter）先撳中。

轉到「桌布實驗」之後：
- 想將「桌布抽出速率」個數字格入面打 1.0：打完撳 Enter，數字完全冇變（仲係 5）。試多次都係咁，個數字輸入格好似打極都唔生效。
- 改用直接撳滑桿條軌，先至郁到個數值（撳到 1.00）。
- 撳「播放」睇個樽：畫面出現細細粒橙色字，好似講緊「桌布仲喺樽下面／桌布抽唔出」呢類嘢，但因為字太細，睇得好辛苦，唔係好肯定寫緊乜。
- 讀數：Δt（摩擦作用時間）= 0.680 s，J（衝量）= 1.00 N·s，Δv（樽獲得嘅速度）= 1.00 m/s
- 再改做 10：用滑鼠撳滑桿撳極都撳唔中 10.0 呢個剛好嘅數（撳嚟撳去得返 8.4 / 9.0 / 9.5，撳唔到正 10，可能個滑桿太幼、唔精確），最後用返 9.5 做「大約 10」。
- 讀數（v布 ≈ 9.5 時）：Δt = 0.0422 s，J = 0.0622 N·s，Δv = 0.0622 m/s
- 比較：抽得快（9.5）嗰陣，Δt、J、Δv 都細好多（差成 16 倍）；抽得慢（1.0）嗰陣，J、Δv 都好大。畫面呢次出現另一句細字，好似講「桌布已抽出，樽喺桌面滑行」。

**做到**（但轉情景嗰步花咗好耐，數值都撳唔到啱好 10）。

### 3. 巴士上的乘客：剔「握扶手」，跳到 t = 8.5 s，睇箭嘴，再取消再睇一次
喺電腦畫面（1440×900）度，我用晒幾種方法都撳唔到「巴士上的乘客」呢個掣（詳細見下面「卡住」）。試過：直接撳、撳兩次、雙擊、換去 1920×1080 再試都係撳唔到，仲試過鍵盤 Tab/Enter/Space，有次仲意外咁跳咗去成個網站嘅首頁（跳走咗個模擬！）。

**喺電腦度呢一步做唔到** —— 已經盡咗力都轉唔到去「巴士上的乘客」情景。

不過我發現去到 iPad（768×1024）闊度嗰陣，撳返同一粒掣即刻work！所以我喺 iPad 度補做咗呢個任務（詳情見下面「iPad 上嘅問題」），喺嗰度我睇到：

- 剔咗「握扶手」，跳到 t = 8.5 s：乘客個公仔身上有 4-5 支箭嘴：藍色向上（R 地板→乘客）、紅色向下（W 地球→乘客）、黑色向左（淨力）、仲有一支細細嘅（好似係紫／綠色）指住「F扶手→乘客」但方向睇落好唔清楚，同埋一支綠色細箭嘴指右（應該係代表速度嘅箭嘴，唔係力）。讀數：淨力 = −180 N，摩擦 = −118 N，F扶手 = −62.3 N。
- 取消「握扶手」再跳到 8.5 s：個乘客公仔喺畫面度真係郁咗去巴士後面（同巴士本身分開咗），身上得返黑色向左（淨力）、紅色向下（W）、綠色向右（v，速度）呢幾支，睇唔到藍色 R 嗰支。讀數：乘客速度 = 7.71 m/s（巴士本身 = 6.50 m/s，即係乘客比巴士快），但「s_rel 乘客相對巴士的位移」讀數係 −8.11 m，個定義寫「正 = 相對巴士向前滑」——我覺得呢度啲數同動畫對唔上：乘客明明快過巴士（應該係向前滑），但個讀數係負數，同時個公仔又真係畫喺巴士後面，睇到我有啲頭暈，唔知邊個先啱。

## iPad 上的問題
- 情景切換掣、「知道了」掣、「跳到 t=」打字輸入，喺電腦度撳唔到／打唔到嘅，**iPad 全部一次就成功**，非常反差。呢個係我覺得最出奇嘅發現：同一個掣，電腦畫面撳極都冇反應，iPad 直向就即刻 work。
- iPad 上整體係單欄排列，唔使橫向滾動，睇落幾舒服，冇撳錯位嘅問題。
- 手指（用滑鼠模擬）撳「已放手」呢類掣，喺 iPad 上第一次就撳中，唔似電腦咁要撳好多次。
- 冇見到有嘢畀個提示框、按鈕遮住睇唔到嘅情況。
- 桌布情景嗰啲細字（橙色提示字）喺 iPad 一樣好細，睇唔清楚寫乜。

## 我卡住的地方（按嚴重程度排）
1. **電腦畫面（1440×900 及 1920×1080）撳「巴士上的乘客」「太空中的飛船」呢兩個情景掣完全撳唔到**——試過直接撳、撳兩次、雙擊、換大個瀏覽器窗都係撳唔到。仲試過鍵盤方式（Tab/Space/Enter），其中一次仲意外跳咗去成個網站首頁，個模擬全部設定同進度都無晒。呢個令到我喺電腦度做唔到第 3 樣老師叫做嘅事。
2. **「知道了」提示框喺電腦度永遠閂唔到**，成程序個橙色提示框都擋喺個模擬上面。
3. **F 外加水平力／桌布抽出速率呢類數字輸入格，喺電腦度打字完全唔生效**，有次仲因為舊字冇被清走，打完個數字變咗「110」咁誇張，令個模擬跑到好癲（s 去到成千米）。
4. **模擬會自己喺背景越走越快**，明明冇撳嘢，t 都由幾秒跳到十幾秒，好難捕捉「啱啱過咗 B 點」呢類指定時刻，要撳好多次暫停先捉到。
5. 曾經有一刻成個頁面完全撳咩都冇反應（撳暫停、撳還原預設都冇用），要離開個模擬頁面再入返先返正常，中途我以為個網站係咪整壞咗／死咗。
6. 桌布抽出速率個滑桿好難撳中剛好嘅整數（例如 10.0），撳極都係 8.4 / 9.0 / 9.5 咁上下。
7. 「巴士上的乘客」取消「握扶手」之後，讀數「s_rel 相對巴士的位移」寫住負數，但乘客個速度明明比巴士快（應該係向前先岩），兩樣嘢睇落矛盾，唔明點解。
8. 「只看淨力」呢個掣撳完全睇唔出畫面有咩分別，唔知做緊咩。
9. 「重播」掣撳完睇唔出即時反應。
10. 細細粒嘅橙色提示字（桌布情景嗰啲）太細，睇得好辛苦。
