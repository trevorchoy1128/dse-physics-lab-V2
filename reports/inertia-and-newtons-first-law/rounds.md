## 第 8 輪學生試用者（環境問題，不是模擬錯誤）
- 報告說「三艘飛船由頭到尾企喺原地」「巴士 f = 0 時鏡頭不跟、只見『巴士中心在 s = … m』一句」「預設 s_rel 全程 0」：前兩項正是第 7 輪之前的畫面（三艘各自鏡頭、鏡頭跟乘客），第三項是試用者自述誤觸了看不見的加速度滑桿（a ≤ 2.5 時本來就不滑）。試用者的瀏覽器窗格在第 7 輪已開着同一網址，第 8 輪只換了 hash，單頁應用沒有重新載入，跑的是第 7 輪的舊 bundle；「參數狀態跨情景、跨重新整理殘留」同一原因。
- 主流程用 Playwright 對同一靜態版（4174，dist 03:20 重建）截圖核實：三艘關引擎 12 s 時藍船 +24 m、灰船 −24 m；f = 0 時整架巴士在畫面內、乘客有「◀ 乘客在 s = 0 m（已滑出車廂）」標記；預設 150 N 煞車 s_rel = −2.99 m（scratchpad/static/、shots/r7-*.png）。
- 兩輪都提出的「⟲ 還原預設會跳回桌面情景」是共用外殼的行為（還原全部控制項含情景），交老師決定是否改為只還原目前情景的參數。
- 已記入 loop.md §7：重派學生試用者前，主流程要在 Playwright 對新 bundle 截圖，並在派工時叫試用者先整頁重新載入（navigate 到不含 hash 的網址再進入）。

## 閘 3 老師檢查後（2026-09-08，版本 0.2.5）
- 老師在 Chrome 發現：太空情景拖推力滑桿時飛船閃動、大小不固定。原因：視野闊度由「預測最遠位移」算出，推力一改比例就變；推力滑桿非即時參數，每拖一格重設運行。
- 修正：桌面與太空情景視野固定（6 m、24 m），不隨參數預測改變；F 與 F引擎 改為即時參數（拖動不重設，等同飛行中調節油門）。Playwright 核實（audit/live-thrust-check.mjs）：改推力三次時間續走（0.87 → 1.43 → 1.97 → 2.52 s），飛船琥珀像素數 202 / 202 / 199 不變。
