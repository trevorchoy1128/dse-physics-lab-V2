# 學生試用：http://localhost:4174/#/sim/inertia-and-newtons-first-law
裝置：電腦 / iPad 直向

## 第一眼
一打開個網址（未撳任何嘢之前），畫面已經唔係喺 t = 0 開始，個時間讀數已經去到 t = 2.41 s，左上角寫住「作用於方塊的力：4 支（水平 2 支）淨力 = -0.0924 N s = 2.40 m」，右邊有個橙色小方塊被隻手推住，仲有 s-t 圖同 v-t 圖已經畫咗一段。第一眼睇，我以為呢個係一個「有隻手推緊個箱喺枱面度郁緊」嘅模擬，但因為一開始個時間就唔係 0，我完全唔知第一步應該撳咩、依家個「已放手」掣係咪已經撳過。撳咗「還原預設」先返到 t = 0.00 s 嘅畫面（呢時見到 3 支力、淨力 0.300 N，個「施力中」掣係橙色/已選中）。

## 老師叫我做的事

### 1. 手推方塊，喺未到 B 點前（約 0.5 秒內）按「已放手」
步驟 → 由 t = 0 開始，撳「播放」，等大約 0.4 秒後撳「已放手」
期望 → 應該可以喺 t 大約 0.4–0.5 秒嗰陣撳到「已放手」
實際 → 完全撳唔中！個模擬喺背景一路繼續行，我等咗大概 0.4 秒（真實時間）先撳「已放手」，一撳落去先發現個模擬入面嘅時間已經跳咗去 t = 5.86 s 先「被放手」（畫面顯示「已於 t = 5.86 s 放手」），時間 t 讀數已經跳到 8.72 s。呢個方法完全做唔到「0.5 秒內」呢個要求。
嘗試次數 → 1 次（完全失敗，之後改用另一個方法）

改用「逐格 0.05 s」呢個掣，由 t = 0.00 s 開始一格一格撳（撳 8 次 = 0.400 s），先撳「已放手」：
- 放手前（t = 0.400 s）：作用於方塊的力：3 支（水平 1 支）　淨力 = 0.300 N　s = 0.120 m　v 速度 = 0.600 m/s
- 撳咗「已放手」之後（同一刻 t = 0.400 s）：作用於方塊的力：2 支（水平 0 支）　淨力 = 0 N　s = 0.120 m（冇變）　v 速度 = 0.600 m/s（冇變）
- 之後再逐格行多幾步（去到 t = 0.550 s），v 仍然係 0.600 m/s，冇慢落嚟。

嘗試次數 → 用逐格方法 1 次就成功
做到 / 做不到 → **用「播放+等時間」方法做不到**；改用「逐格」方法後**做到**。方塊放手後速度冇慢落嚟（因為 A 到 B 呢段桌面係光滑，冇摩擦）。

### 2. 剔「第二個方塊（同一推力）」，播放約 1 秒後按「已放手」
步驟 → 剔咗「第二個方塊（同一推力）」checkbox，用「逐格」撳 20 次去到 t = 1.00 s，撳「已放手」
期望 → 兩個方塊質量唔同（原本嘅 0.2 kg vs 第二個預設 1 kg），應該一個郁得快啲一個郁得慢啲；放手後兩個嘅速度應該分別維持唔變
實際 → 喺 t = 1.00 s：方塊 A（0.2 kg）已經行咗 0.750 m（啱啱過咗 B 點），v = 1.50 m/s，但已經開始因為過咗 B 而受摩擦減速；方塊 B（1 kg）先行到 v_B = 0.300 m/s，仲喺光滑段。撳「已放手」之後：F 外加水平力歸零，方塊 A 因為已經過咗自己嗰個 B 點，仍然有摩擦力（f = -0.392 N）令佢繼續減速；方塊 B 未過自己嗰個 B 點，v_B 保持 0.300 m/s 唔變。
畫面上分唔分得出邊個係方塊 A、邊個係 B？→ **分唔到**。畫面上兩個方塊個外觀（橙色公仔 + 手推力箭嘴）完全一樣，冇任何文字標籤寫住「A」定「B」，淨係喺 v-t 圖下面有一句細字圖例「線 = 方塊 A（較深色），鈍 = 方塊 B」，要專登睇嗰句先知邊條線係邊個方塊，方塊本身喺場景圖度冇標示。
嘗試次數 → 1 次
做到 / 做不到 → 讀數部分做到；「分邊個係邊個」呢點做不到（要睇圖表圖例先知）

### 3. 桌布實驗：抽出速率 5 vs 10，睇 t=1s 嘅 J
步驟 → 換情景去「桌布實驗」，確認「桌布抽出速率」= 5（預設），輸入「跳到 t =」= 1，讀 J；再改做 10，一樣跳到 t = 1，讀 J，比較條長
期望 → 我以為抽得越快，衝量應該越大（直覺諗法：拉快啲應該「撞」得大力啲）
實際 →
- 速率 = 5：Δt 摩擦作用時間 = 0.0810 s，J 衝量 = 0.119 N·s，Δv = 0.119 m/s
- 速率 = 10：Δt 摩擦作用時間 = 0.0401 s，J 衝量 = 0.0590 N·s，Δv = 0.0590 m/s

即係速率越快，J 反而**細咗**，同我估計相反，唔明點解（冇睇說明，純粹靠讀數）。
畫面上面嗰條「衝量條」（一條幼長嘅白色方框）兩次睇落都好幼、好似冇乜填色，肉眼完全睇唔出兩次條長有咩分別，要靠底下嘅數字先知道差異。
嘗試次數 → 1 次
做到 / 做不到 → 讀數部分做到；「比較條長」呢點做不到（睇唔出條有分別）

## 每個控制項我以為是做甚麼
| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| ▶ 播放 / ⏸ 暫停 | 開始/停止個動畫 | 撳咗真係郁/停，但個模擬一路喺背景行，暫停都追唔切精確時間 |
| ⏭ 逐格 0.05 s | 一步步向前行少少 | 每撳一次時間 +0.05 s，冇自動亂跳，係最準嘅方法 |
| ↺ 重播 | 估計係由頭重播一次 | 冇專登試 |
| ⟲ 還原預設 | 清晒改動，返去原本設定 | 撳咗之後個模擬會自動由 t=0 一路播落去，唔會停低，要自己再撳暫停先追得切 t=0 |
| 情景（水平桌面上的方塊 / 桌布實驗 / 巴士上的乘客 / 太空中的飛船） | 換唔同場景睇 | 撳咗真係換晒成個畫面、滑桿同讀數，但唔一定自動 reset 到 t=0 |
| 施力中 / 已放手 | 控制隻手有冇推住個方塊 | 撳「已放手」個紫色施力箭嘴即刻消失，力嘅支數同淨力即刻變 |
| F 外加水平力（滑桿+數字） | 調較個推力大細 | 改咗個數，畫面嘅「尺」刻度同 A、B 位置標記會跟住大幅度變，A、B 兩個字幾乎疊埋一齊，睇唔清 |
| m 方塊質量（滑桿+數字） | 調較方塊有幾重 | 改大咗方塊圖示變大，個尺又跟住變 |
| μ₁ 前段桌面（A至B）的摩擦係數 | 調較 A 到 B 呢段有幾滑 | 改成 0.1，即刻見到橙色摩擦箭嘴出現，淨力數值變細 |
| μ₂ 後段桌面（B之後）的摩擦係數 | 調較 B 之後有幾「渋」 | 改成 0.5，標籤「B之後 μ=0.500」即刻變，但 t=0 未睇到效果因為方塊仲喺 A 未過 B |
| 第二個方塊（同一推力） checkbox | 加多一個方塊一齊比較 | 剔咗真係加多一條桌、多一條線，但兩個方塊個外觀一模一樣分唔出邊個係邊個 |
| g 重力加速度（下拉） | 調較地心吸力大細 | 揀咗「10」，睇落嘅讀數（淨力、v、a）冇明顯反映有咩唔同，唔知呢個掣做緊咩 |
| 顯示：重量 / 法向反作用力 / 摩擦 / 施力 / 淨力 / 速度箭嘴 / 加速度箭嘴 / 只看淨力 | 開關唔同箭嘴顯示 | 剔走「重量」，紅色 W 箭嘴即刻喺畫面消失，證實係開關掣 |
| 跳到 t =（滑桿+數字框） | 直接跳去某個時間 | 打數字撳 Enter 真係即刻跳到嗰一刻，幾好用 |
| 速度（播放速度 0.1×–2×下拉） | 估計係控制動畫播放快慢 | 冇專登試 |
| 桌布實驗：v布 桌布抽出速率 | 調較拉桌布有幾快 | 改成 5 或 10，右邊 Δt、J、Δv 讀數都跟住變，但方向同我估嘅相反（越快 J 越細） |
| 桌布實驗：布與物件之間的摩擦係數 / 物件與桌面之間的摩擦係數 / 物件下方的桌布長度 | 估計係調較另外幾個摩擦力/長度數值 | 冇專登試 |

## 畫面上的數字
| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| t 時間 | 現在播到第幾秒 | 有（s） |
| F 淨力（向右為正） | 個方塊實際受嘅總力 | 有（N） |
| v 速度 | 方塊而家有幾快 | 有（m/s，寫成 m s⁻¹） |
| a 加速度 | 方塊而家加速定減速緊，有幾快 | 有（m/s²） |
| s 位移 | 方塊由開始行咗幾遠 | 有（m） |
| f 摩擦（向右為正） | 摩擦力大細 | 有（N） |
| F 外加水平力 | 隻手/引擎推嘅力 | 有（N） |
| v_B 第二個方塊速度 | 第二個方塊嘅速度 | 有（m/s） |
| v布 桌布速度 | 桌布本身郁得幾快 | 有（m/s） |
| Δt 摩擦作用時間 | 桌布仲喺方塊底下嘅時間 | 有（s） |
| J 衝量 J = fΔt | 力乘時間，估計係「衝量」呢個物理量 | 有（N·s） |
| Δv 物件獲得的速度 | 方塊因為衝量而得到嘅速度 | 有（m/s） |
| d 抽出後的滑行距離 | 桌布抽走之後方塊仲會滑幾遠 | 有（m） |

## iPad 上的問題
- 版面變成單欄直排，全部控制項（滑桿、掣、checkbox）都掉晒落去落面，唔使橫向滾動就見到，呢點幾好。
- 轉咗做 iPad 尺寸之後，第一次用返之前（電腦版）記低嘅按鈕座標去撳「逐格」同「跳到 t=」，撳唔中正確位置——撳 8 下「逐格」本來想去到 0.4 秒，點知個時間跳咗去 3.70 秒，即係撳中咗其他嘢（可能係嗰條時間滑桿）。要重新截圖確認實際掣喺邊度先撳得中。
- 之後用啱嘅座標撳「逐格」8 次去到 t = 0.400 s，撳「已放手」，結果同電腦版一樣：v = 0.600 m/s，放手前後冇變。
- 期間個網站自己好似「重新整理」咗一次：時間突然跳到 12.0 s（成個模擬播完晒），仲彈咗個之前冇見過嘅教學提示框出嚟（有 1、2、3 點步驟，同一個「知道了」掣）。呢個喺電腦版一開始冇見過，好突然，唔知做錯咗咩。

## 我卡住的地方（按嚴重程度排）
1. **一開頁個模擬已經自動播緊，而且一直喺行緊，想喺一個好精確嘅時間點（0.5 秒內）撳「已放手」根本撳唔中**——用「播放」再等時間再撳呢個最直覺嘅做法，撳落去先發現時間已經跳咗去 5.86 秒先算「放手」，同我想要嘅 0.5 秒差好遠。要老師特登講嘅「逐格」功能先做到。一個普通學生淨係識用滑鼠撳「播放」再眼睇時間撳掣，好大機會撳唔中。
2. **「還原預設」撳咗之後個模擬會自動繼續由頭播到尾**，唔會停低喺 t=0，搞到我每次截圖見到嘅時間都唔係 0，要再撳多一次「暫停」先追得切。呢個好易畀學生以為個網站係咪壞咗、個方塊點解自己識喺度郁。
3. **兩個方塊（A/B）喺畫面上完全冇文字標籤，一模一樣嘅橙色公仔圖示**，淨係識靠落面 v-t 圖嘅圖例細字「線 = 方塊 A，鈍 = 方塊 B」先分到邊條線係邊個，方塊本身喺場景圖完全冇標示邊個係邊個。
4. **改「F 外加水平力」呢類滑桿嗰陣，畫面嘅「尺」（ruler）刻度連同 A、B 兩個位置標記會即刻大幅度變（縮放/移位）**，試過改到 A、B 兩個字幾乎疊晒喺一齊，好難認得出邊個係邊個。
5. **桌布實驗嗰條「衝量條」視覺化條**，兩次改速率（5 同 10）條長睇落都係好幼、好似冇乜填色，肉眼分唔出兩次有咩分別，要靠底下數字先知道。
6. **「g 重力加速度」下拉揀完全睇唔出邊個讀數郁咗**，唔知呢個掣實際上改緊咩，用咗都好似冇分別。
7. **轉咗 iPad 尺寸之後，之前記低嘅按鈕位置會唔啱**，第一次撳「逐格」撳中咗其他嘢，令時間跳得好亂，要重新截圖先搵返啱嘅位置。
8. **試用期間出現一次頁面自己重新整理**，時間跳到播完晒、彈咗個未見過嘅教學提示框，好突然，唔知係咪自己撳錯咗嘢。
