# 學生試用：http://localhost:4174/#/sim/inertia-and-newtons-first-law
裝置：電腦 / iPad 直向

## 第一眼
未按任何嘢之前，個畫面分兩邊：左邊係一個白色桌面場景，有個橙色方塊喺度、幾條箭嘴（藍、紅、紫），下面仲有三個細細的線圖；右邊有一大堆滑桿同掣，寫住「情景」「水平外力」「F外加水平力」之類。標題話「慣性與牛頓運動第一定律」。

老實講，我第一眼唔知要撳邊度。個場景已經自動喺度郁緊（個時間讀數同個方塊都喺度變），感覺好似個模擬自己已經開始咗，唔使我撳。畫面中間有一個橙色提示框寫住「1 方塊已經被一支 0.30 N 的力推着…按右邊的「已放手」」，睇到嗰行字先知道第一步要撳邊粒掣（已放手），如果冇嗰段字我應該會亂咁㩒滑桿。

## 老師叫我做的事

### 1. 水平桌面上的方塊：放手 + 後段摩擦力拖到 0
步驟：先睇住方塊畀 0.3N 力推住郁緊（沒過 B 點時撳「已放手」試咗一次，之後又試等佢過咗 B 點先撳「已放手」）。
- 期望：撳「已放手」之後，如果方塊已經過咗 B（粗糙路面），佢應該會慢慢停低（因為摩擦力）。
- 實際：方塊過咗 B 之後撳「已放手」，橙色「摩擦」箭嘴出現指向後，方塊真係減速，最後停咗（v = 0.00 m/s，淨力 = 0.00 N，位移停喺 1.45 m）。做到。
- 嘗試次數：3 次（第一次過早撳、第二次要重新用「還原預設」再嚟、第三次先啱）。

把「後段桌面（B 之後）的摩擦力」拖到 0，撳「重播」：
- 期望：呢次方塊過咗 B 之後放手應該唔會停，會一直等速郁。
- 實際：撳「重播」之後個「已放手」狀態冇還原返做「施力中」，方塊企喺原地唔郁（因為冇力推佢），我要自己再撳返「施力中」先再推到佢過 B。之後撳「已放手」，方塊真係一直等速前進（v 定喺 1.75 m/s、淨力 0.00 N），冇停低。做到。
- 嘗試次數：約 4 次（因為撳「重播」之後見到個「已放手」掣狀態同個時間讀數都冇跟住歸零，搞唔清楚係咪撞咗一次程式壞咗）。

**觀察到嘅分別**：第一次（後段有摩擦 0.4N）放手後方塊會停；第二次（後段摩擦拖到 0N）放手後方塊永遠唔停、等速前進。淨力讀數：有摩擦時放手一刻係 -0.400 N，之後慢慢變返 0；冇摩擦時放手一刻同之後都係 0.00 N。

### 2. 桌布實驗：抽出速率 5 → 10 → 1.0
- 預設 v布 = 5 m/s：Δt = 0.0810 s、J = 0.121 N s、Δv = 0.121 m/s（樽差唔多冇郁，因為布好快就抽走）。
- 改 v布 = 10：撳「重播」後畫面完全冇郁，個時間讀數卡喺 0.00 s 唔郁，等咗成 4 秒都係咁；跟住我照住提示「先按一下畫面再等一秒」撳咗個場景一下，先郁返（跳到 1.16 s）。結果：Δt = 0.0401 s、J = 0.0602 N s、Δv = 0.0602 m/s，樽幾乎完全冇郁（滑行距離得 9.05×10⁻⁴ m）。
- 改 v布 = 1.0：撳「重播」後又係要撳一下畫面先郁。呢次樽被布「拖住走」，追上咗布速（v = 1.00 m/s = 布速），J = 1.00 N s、Δv = 1.00 m/s，畫面見到樽同布一齊向右移咗好遠（1.85 m），最後跟住鏡頭跑出咗枱邊，有段紅色字（字好細睇唔清楚，大概講緊「桌布太慢，樽跟住布一齊走」）。
- 三次比較：抽得越快（v布 越大），樽留喺原地嘅機會越大、J 同 Δv 越細；抽得好慢（1.0 m/s），樽反而被布拖走，冇「來不及反應」呢種效果。

### 3. 巴士上的乘客：摩擦力 0 → 240，睇急煞
把「地板對乘客（鞋）的摩擦力」拖到 0，撳「重播」：
- 期望：巴士起步，乘客應該企喺原地唔識郁（因為冇摩擦拉住佢）。
- 實際：撳「重播」後又係卡住冇郁，撳一下畫面先開始。之後見到巴士自己開走（v車 最終 3.5 m/s 咁上下），乘客企喺度完全唔郁（v = 0.00 m/s），s_rel（乘客相對巴士）變到 -1.90 m，即係喺巴士角度睇，乘客好似「被拋到後面」咁樣越拉越遠。做到。

改做 f = 240 N，撳「重播」：
- 實際：呢次乘客同巴士一齊加速（v 同 v車 幾乎一樣，s_rel 定喺 0.00 m），冇滑動。用「跳到 t =」揦到 t = 9.5 s（啱啱好係「急煞」個段），見到乘客身上有兩支箭嘴：一支橙色寫「f 地板→乘客（摩擦）」、一支黑色粗嘅寫「淨力」，兩支都係指向**左**（即係「後面」，同巴士行進方向相反），完全冇見到有向前（右）嘅箭嘴。呢個同老師提到嘅「巴士急煞時有一股力把乘客推向前」個講法唔同，畫面反而顯示力係向後嘅。
- 做到，但要留意：「跳到 t =」呢個輸入格喺電腦某個視窗闊度會撞到一個好嚴重嘅版面 bug（見下面「卡住嘅地方」第 1 點）。

| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| t 時間 | 過咗幾多秒 | 有，s |
| F 淨力（向右為正） | 全部力加埋一齊嘅結果 | 有，N |
| v 速度 | 物件行得幾快 | 有，m s⁻¹ |
| a 加速度 | 速度變化得幾快 | 有，m s⁻² |

**沒有見到「μ」或「摩擦係數」呢啲字**，成個模擬入面摩擦力全部都係用 N 做單位嘅力（f₁、f₂、f布、f桌、f），冇見過任何「摩擦係數」呢個講法。

## iPad 上的問題
- iPad 直向（768×1024）反而**冇**遇到電腦版嗰個嚴重嘅版面 bug——控制項全部變成一條直落嘅版面（場景 → 三個線圖 → 參數 → 顯示 → 讀數 → 試試看），逐個都撳到、睇到，冇被遮住。
- 觸控目標睇落都夠大（「已放手」「施力中」呢啲掣成粒都可以撳），冇撳唔中嘅情況。
- 都係遇到同電腦版一樣嘅「撳咗重播/施力中之後，時間讀數卡住唔郁」情況，要撳一下個場景先郁（見下面共通問題）。
- 冇需要橫向滾動嘅地方。
- 「跳到 t =」喺 iPad 度用一切正常，冇好似電腦版咁整爆版面。

## 我卡住的地方（按嚴重程度排）
1. **（電腦版，好嚴重）右邊嘅「參數／顯示／讀數」控制版面會整個消失/變成一大片空白**：喺電腦視窗（本身個瀏覽器窗格闊度，我冇自己改過）向落捲個頁面，過咗個場景同三個線圖之後，落面應該有嘅「參數」「顯示」「讀數」全部變成純白色空白，睇唔到任何字或者滑桿，但用 read_page 工具check翻DOM，啲控制項（例如「巴士起步／煞車的加速度」）其實都喺度，只係冇畫出嚟。呢個情況喺我用咗「跳到 t=」輸入格之後特別容易出現，之後就算撳返個網址重新入都仲係咁。學生喺呢個情況下完全冇辦法用滑桿改參數，等於個模擬廢咗。（因為睇唔到，我後尾要靠 find 工具盲估位置先撳到掣。）
2. **「重播」掣冇可靠咁做返 t = 0**：好多次撳「重播」之後個時間讀數唔係跳返去 0.00 s，反而停喺撳嗰刻附近嘅數值（例如由 1.12 s 變成 1.06 s），要撳多幾次或者配合「還原預設」先真係由頭嚟過。學生會以為個掣壞咗或者自己冇撳中。
3. **撳「播放」之後，時間讀數/物件位置成幾秒都唔郁**：呢個喺三個任務入面全部都遇到過，撳晒「播放」之後等 2-3 秒都冇反應，一定要用滑鼠喺個場景度撳多一下先會繼續行。如果唔係老師/題目度提我「若時間讀數不走，先按一下畫面再等一秒」，我自己絕對估唔到要點做，會以為個模擬壞咗。
4. **「還原預設」會連「情景」都一齊變返做「水平桌面上的方塊」**：如果我啱啱喺「桌布實驗」度撳咗「還原預設」想淨係還原個情景入面嘅參數，點知成個畫面跳走去第一個情景，要再撳一次「桌布實驗」先返到嚟，有少少嚇親。
5. 桌布實驗 v布=1.0 嗰次，畫面有段紅色細字提示（好似講緊桌布抽唔出/樽跟住走），但隻字太細睇唔清楚寫乜。
