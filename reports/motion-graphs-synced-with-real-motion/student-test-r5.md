# 學生試用：http://localhost:5173/#/sim/motion-graphs-synced-with-real-motion

裝置：iPad 直向（768×1024，先做）→ 電腦（還原 desktop 後再做一次）

## 第一眼
（未按任何東西前，iPad 直向）

打開網址之後，畫面最頂係標題「運動線圖與真實運動同步」，下面有一排按鈕（播放、逐格0.1s、重播、還原預設、速度）同一條「跳到 t=」的滑桿，睇得出應該係關於畫線圖同小車運動嘅模擬。

但係最古怪嘅係：一開頭三張圖（同中間果條小車軌道）全部都係**模糊一片、有殘影**，好似張相冊爆咗或者個動畫已經播緊好快咁樣重疊埋一齊，完全睇唔到任何清楚嘅線或數字。我第一下以為個網頁壞咗/未load完，唔知道應該按邊個掣先。過幾秒（撳咗「重播」之後）先變返清楚。

睇到下面有兩粒掣「由運動生成圖：我控制小車」同「由圖生成運動：我畫 v–t 圖」，但一開始入嚟嗰陣「由圖生成運動」呢粒係已經揀咗（深綠色），我唔知道點解一開波就係「畫圖」模式，仲以為要撳「控制小車」先啱。完全冇任何文字話你聽第一步應該撳邊粒掣。

## 老師叫我做的事

### 1. 讓小車先向右行，然後停下來，再倒後行。做到之後，看看三張圖分別變成甚麼樣子
步驟：撳「由運動生成圖：我控制小車」→ 將「u 初速」設做 3、「a 加速度」設做 -1 → 撳「播放」

期望：小車向右郁一陣，慢慢減速，停一停，再反過來向左行。

實際：撳「播放」之後，等咗成 5 秒鐘現實時間，畫面先至由 t=0 行到 t=0.14 秒（本來個「速度」揀單係寫「1×」，但完全唔係1秒行1秒，慢到好誇張）。用「播放」根本冇可能睇完成個 10 秒嘅運動，所以我改用「跳到 t=」條滑桿/輸入格直接跳去 t=3、t=7 睇個結果：
- t=3s：小車啱啱停低（s=4.5m，v=0），s-t 圖去到最高點，v-t 圖啱啱掂到0，a-t 圖係一條平嘅負數線。
- t=7s：小車已經反轉向左行（箭嘴指返左），s=-3.5m，s-t 圖由頂跌返落嚟（好似拋物線）、v-t 圖係一條由正到負嘅直線、a-t 圖仍然係嗰條平線，冇變過（因為加速度一直冇變）。

嘗試次數：撳「播放」等咗兩次（各5秒）先發現太慢，之後改用跳到 t= 嘅方法一次搞掂。

做到 / 做不到：**做到**（但要用跳時間嘅方法，唔係真係睇住佢慢慢郁）

### 2. 找出小車在 t = 4 s 時的速度是多少，並且說出你是從畫面哪裏得到這個數字
步驟：用「跳到 t=」輸入格打 4，撳 Enter，然後向下拉揭到「讀數」個表。

實際：讀數表顯示：t 時間 = 4.00 s，v 速度 = -1.00 m s⁻¹（同埋 s=4.00m、a=-1.00m/s² 等等）。

負號代表小車喺呢一刻已經反轉緊向左行。呢個數字係喺參數欄下面「讀數」嗰一格見到，唔係喺三張圖度直接見到（三張圖淨係見到一條虛線切線加「斜率」文字，冇直接寫出t=4嗰一刻嘅速度數值）。

嘗試次數：1次（第一次打4之後直接見到）

做到 / 做不到：**做到**

### 3. 把模式改成「由圖生成運動」，畫一個「先快後慢、然後停住」的 v–t 圖，按播放，看看小車是不是這樣走
步驟：撳「由圖生成運動：我畫 v–t 圖」→ 用手指/滑鼠拖動 v-t 圖上面果 11 粒小圓點，將第一粒拉到好高（表示一開始好快），跟住逐粒拉低，去到中間之後全部拉到 0（表示停低）→ 撳「播放」。

期望：小車一開始行得快，之後越行越慢，最後完全停低唔郁。

實際：拖圓點嗰陣好唔穩定：
- 有兩次拖完之後，成個 App 突然自己跳返去「由運動生成圖：我控制小車」個模式，仲自動開始播放（u、a變返0、1嘅預設值），我畫緊嗰個圖完全不見咗，要由頭嚟過。
- 有幾粒圓點（例如t=6、t=7嗰兩粒）試咗兩三次先至拖得郁，之前兩次完全冇反應（畫面一啲都冇變）。
- 有一次我想拖第5粒(t=5)，結果實際上改咗嘅係第6粒(t=6)嘅數值，即係好易拖錯粒。

畫好之後撳「播放」，呢次冇再跳走返去第一個模式，睇到小車真係向右行，越行越慢，跳去 t=10 睇到 v=0、a=0，s定咗喺 15.5m，同我畫嗰個「先快後慢、停低」嘅圖係啱嘅。但係 a-t 圖出咗嚟係一格格上上落落嘅樓梯形（因為我啲點冇拉到啱啱好平滑遞減），如果唔識，會以為架車加速度係跳來跳去，其實只係因為我啲點冇拉得夠準。

嘗試次數：拖點嘗試咗超過 15 次先砌到一個大致得嘅圖形（因為中途兩次成個模式跳走咗，要由頭嚟）

做到 / 做不到：**做到**（但過程好唔順、好易畫緊畫緊全部凍過或者reset晒）

## 每個控制項我以為是做甚麼

| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| ▶ 播放 / ⏸ 暫停 | 開始/暫停個動畫 | 啱嘅，但播放速度好慢，「1×」都唔似1秒=1秒 |
| ⏭ 逐格 0.1 s | 一格格咁前進睇動畫 | 啱，撳一次t準確加0.1秒，反而係最好用嘅睇結果方法 |
| ↺ 重播 | 由頭再嚟 | 撳完t歸零，但唔會改返個模式（如果之前你揀咗控制小車，重播後仍然係控制小車） |
| ⟲ 還原預設 | 我以為淨係將啲數值(u、a)變返原本 | 除咗數值變返原本，仲會**切返去「控制小車」模式並自動開始播放**，冇講過會自動播 |
| 速度（1× 落拉選單） | 調較播放快慢 | 淨係得 0.1×/0.25×/0.5×/1×/2× 幾個選擇，但就算揀2×都仍然覺得好慢 |
| 跳到 t= （滑桿/輸入格） | 直接跳去某一秒 | 好用，跳得好準，但用鍵盤打完數字之後如果撳Tab（唔係Enter）有機會令成個App reset走，要撳Enter先安全 |
| 由運動生成圖：我控制小車 | 用滑桿設定初速、加速度嚟郁架車 | 啱 |
| 由圖生成運動：我畫 v–t 圖 | 自己喺v-t圖度畫線嚟決定架車點行 | 啱，但拖圓點好唔穩定 |
| u 初速 滑桿/輸入格 | 設定架車一開始嘅速度 | 啱 |
| a 加速度（可隨時改）滑桿/輸入格 | 設定架車嘅加速度，正負決定加速定減速 | 啱，設做負數會令架車減速、停、再反方向 |
| T 時間窗 / s（5/10/20s） | 我以為係整條片有幾長 | 冇特登去試，估計係圖表橫軸顯示範圍 |
| 速度箭嘴（checkbox） | 顯示/隱藏架車個「v」箭嘴 | 啱，剔走之後箭嘴不見咗 |
| 加速度箭嘴（checkbox） | 顯示/隱藏架車個「a」箭嘴 | 啱 |
| 切線（斜率）（checkbox） | 唔明係做咩，感覺同「斜率」有關 | 剔走之後，圖上面嘅虛線同「斜率=...」文字全部不見咗，即係呢個掣係開關嗰條切線同斜率數值 |
| 線下面積（checkbox） | 唔明 | 剔咗之後v-t圖下面出現咗一片淺色底色，加埋個「面積=...m」數字，即係顯示曲線下面積（應該係代表位移） |
| v-t圖上嘅小圓點（拖動） | 拖上拖落嚟改果一秒嘅速度 | 啱，但好難拖得準，成日拖唔郁或者拖錯隔籬粒 |

## 畫面上的數字

| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| t 時間 | 現在去到第幾秒 | 有，s |
| s 位移 | 架車離開起點嘅位置（有正負，代表方向） | 有，m |
| d 路程 | 唔知同「位移」有咩分別，睇落應該係總共行咗幾遠（唔理方向） | 有，m |
| v 速度 | 架車依家行緊幾快，正負代表方向 | 有，m s⁻¹ |
| a 加速度 | 架車依家加速定減速緊，幾快 | 有，m s⁻² |
| v-t線下面積 | 話畀你知呢個等於位移 | 有，m |
| 平均速率（路程÷時間） | 平均嚟講行得幾快（唔理方向） | 有，m s⁻¹ |
| 平均速度（位移÷時間） | 平均嚟講位置變化幾快（計方向） | 有，m s⁻¹ |
| 每張圖上面嘅「斜率 = ...」 | 個切線嘅斜率數值 | 有單位，但s-t同v-t圖嗰兩條斜率單位唔一樣(m/s vs m/s²)，冇特別解釋 |
| 「斜率 = 2.19 × 10⁻¹⁵ m s⁻¹」（曾經見過一次） | 完全睇唔明呢個係咩，得個大堆數字加個負十五次方 | 有寫單位，但個數本身太怪，唔明佢想講「大約係0」 |

## iPad 上的問題

- 手指要拖v-t圖上面粒圓點嚟畫圖，粒點好細，經常拖唔中，或者拖咗但完全冇反應，要試好多次。
- 冇見到要橫向滾動嘅地方，成個頁面喺768px闊都排到一欄，睇落冇嘢俾遮住。
- 「跳到 t=」個輸入格喺iPad用手指triple-click揀晒個數字之後打字，同電腦用滑鼠一樣容易，冇特別問題。
- 但係同電腦一樣，全部功能喺iPad試多幾次都一樣會撞到「拖完圖之後全個App自己reset返去控制小車模式仲自動播放」呢個問題，唔係得iPad先有。
- 三張圖同小車軌道喺iPad螢幕度會比較細，睇個「斜率」、「面積」呢啲細字要瞇埋眼先睇到。

## 我卡住的地方（按嚴重程度排）

1. **最嚴重**：用「由圖生成運動」畫v-t圖嗰陣，成個App會冇啦啦自己跳返去「控制小車」模式，仲自動開始播放，之前拖好嘅圖完全不見咗，要由頭再畫。發生咗兩次，冇啦啦嘅，唔知點解會咁，唔知點樣避免。
2. 「播放」個速度同標示嘅「1×」完全對唔上，等足5秒現實時間，個模擬先至行咗0.14秒左右，如果唔識轉用「跳到t=」，根本冇可能睇完一次完整運動。
3. v-t圖上面嘅小圓點好難用滑鼠/手指拖得準，成日要試兩三次先拖得郁，甚至試過拖錯咗隔籬嗰粒。
4. 撳「還原預設」會自動開始播放，冇講過，第一次見到時唔知點解啲數字自己郁緊。
5. 喺「跳到t=」輸入格打完數字之後如果撳Tab鍵（唔係撳Enter），試過幾次成個App狀態亂晒（模式、u、a全部變返預設，仲開始播放）。
6. 一開波未撳任何嘢，三張圖同小車軌道會顯示模糊殘影，好似個網頁壞咗，過幾秒撳「重播」先變返正常。
7. 「斜率 = 2.19 × 10⁻¹⁵ m s⁻¹」呢類科學記數法數字，完全睇唔明，會以為個計算出錯。
8. 一開始入嚟個page，「模式」預設係「由圖生成運動」定係「由運動生成圖」好似冇固定，兩次載入見到唔同結果，唔知係咪記住咗我上次揀嘅嘢。
