# 學生試用：http://localhost:5173/#/sim/motion-graphs-synced-with-real-motion

裝置：電腦 / iPad 直向

## 第一眼

（未按任何東西前）

打開網址，畫面分成上下兩半：上面是一條數線和一架小車，小車上面有兩個綠色箭嘴（v 和 a），下面是三張並排的小圖（s-t 圖、v-t 圖、a-t 圖），右邊有一堆滑桿和選單叫「參數」。

我第一眼以為這是「畫小車移動的三張圖」的東西，但奇怪的是：我還沒按任何按鈕，畫面已經自己在動了——上面顯示的 `s = 0.0192 m` 這類數字一直在變，v-t 圖上的虛線切線也在慢慢移動。所以我不知道「第一步該按什麼」，因為它根本不用我按就自己開始播放了。如果是老師沒教過的學生，可能會以為壞了/自動在跑一些看不懂的東西。

## 老師叫我做的事

### 1. 讓小車先向右行，然後停下來，再倒後行，看三張圖變化
步驟：保持預設「由運動生成圖：我控制小車」模式，初速 u=0、加速度 a=1，按播放讓車子先加速向右幾秒，再把「加速度」數字框改成 -1，等速度降到 0 再變負。
期望：小車向右→慢下來→停→倒後移動；三張圖應該相應改變。
實際：做到了。觀察到：
- s-t 圖：本來是一條往上彎的曲線（愈來愈斜向上），改成減速後曲線頂點翹起，然後開始往下彎（代表位置在減少，即往回走）。
- v-t 圖：本來是一條由 0 開始向上的直線，改加速度後變成連續的一條直線，先繼續上升一點點、再往下穿過 0 那條橫線、繼續往負的方向走——原來速度圖是「一條直線」，不是分開兩段。
- a-t 圖：本來是一條水平線在 +1 的位置，改了之後立刻「垂直跳下去」變成一條在 -1 的水平線，中間是直上直下的一條線（像樓梯）。
嘗試次數：2 次（第一次等太久沒注意 v 有沒有過 0，第二次配合截圖確認 v 變負才停手）。
做到 / 做不到：做到。

### 2. 找出小車在 t = 4 s 時的速度
步驟：延續第 1 題的模擬繼續播放，不斷截圖查看右邊「讀數」面板的 `t 時間`，等它接近 4 秒時按暫停。
期望：能精準看到 t=4.00s 那一刻的 v。
實際：無法精準停在剛好 4.00 s——按暫停時停在 t=4.15 s（也試過 3.97s 那次），讀到 `v 速度 = -2.97 m s⁻¹`（在右邊「讀數」面板的 v 那一行讀到的）。沒有找到可以直接輸入「t=4」跳過去的功能，只能用眼睛盯著數字按暫停，誤差有 0.1~0.2 秒左右。
嘗試次數：反覆截圖等待接近 10 次以上才抓到接近 4s 的畫面。
做到 / 做不到：大致做到（有誤差，抓不準剛好 4.00s）。

### 3. 切換「由圖生成運動」，畫一個「先快後慢，然後停住」的 v-t 圖，按播放
步驟：把「模式」下拉選單改成「由圖生成運動：我畫 v–t 圖」，然後在 v-t 圖上拖動空心圓點，把最左邊的點拉到最高、之後幾個點逐步拉低、最後幾個點拉到 0 線，再按播放。
期望：小車一開始跑得快，然後愈來愈慢，最後停住不動。
實際：
- 切換模式時第一個大問題：滑鼠點下拉選單、點選項，完全沒有反應，選單文字一直停在「由運動生成圖：我控制小車」。試了滑鼠點擊 5、6 次都不行，後來改用鍵盤（點一下選單、按 End、按 Enter）才切換成功。如果不知道用鍵盤，這一步是切不過去的。
- 拖動圓點很難準：圓點很小，我目測座標去拖，常常「明明拖了但畫面沒反應」（拖空了），要重試好幾次才拖到看起來像樣的形狀。
- 最後畫出來的線不是完全平滑遞減，中間有一小段凹凸（可能是我拖得不夠準）。按播放後，小車確實先跑得比較快、然後變慢，但因為線不是完全單調下降，中途速度竟然有一小段「回升」（讀數面板的 a 一度變成 +0.800，速度從 2.30 升到 2.67 m/s），跟我原本想畫「一直減速到停」不完全一樣——這可能是我畫得不夠準，但也说明只要手不夠穩，畫出來的線跟小車實際表現會不一致，蠻難一次成功的。
嘗試次數：模式切換試了 6+ 次才成功；拖點大約 10 次操作才畫出大致形狀。
做到 / 做不到：大致做到（車子有先快後慢的趨勢，但不是完全單調，也沒等到完全停下來就結束觀察）。

## 每個控制項我以為是做甚麼

| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| 模式（由運動生成圖 / 由圖生成運動） | 切換「我控制小車」還是「我畫圖控制小車」兩種玩法 | 用滑鼠點選項沒反應，要用鍵盤 End+Enter 才能切換；切換後界面內容不同（有無 u/a 滑桿） |
| u 初速 / m s⁻¹ | 設定小車一開始的速度 | 改了之後車子一開始的速度確實變了，讀數面板的 v 起始值也對應改變 |
| a 加速度（可隨時改）/ m s⁻² | 設定小車的加速度，正代表向右加速、負代表減速或倒後 | 播放中途改這個數字，車子真的會變快/變慢/倒退，跟預期一致 |
| T 時間窗 / s | 以為只是改變圖表橫軸顯示範圍（例如看 5 秒還是 20 秒） | 改了之後整個模擬會直接歸零重新開始（t 變回 0.00s），有點意外，本來以為只是「放大縮小」畫面 |
| 速度箭嘴（checkbox） | 顯示/隱藏小車上方那個綠色 v 箭頭 | 關掉後箭頭真的消失，符合預期 |
| 加速度箭嘴（checkbox） | 顯示/隱藏小車上方那個綠色 a 箭頭 | 關掉後箭頭消失，符合預期（但如果 a=0 時本來就看不到箭頭，不確定是這個開關的作用還是因為 a 是 0） |
| 切線（斜率）（checkbox） | 顯示/隱藏圖上那條虛線和「斜率=...」文字 | 關掉後虛線和文字都不見了，符合預期 |
| 線下面積（checkbox） | 把 v-t 圖曲線下面的地方塗顏色 | 打開後 v-t 圖真的出現一塊淡色陰影，而且旁邊寫的「面積」數字剛好跟「位移 s」的數字一樣 |
| ▶ 播放 / ⏸ 暫停 | 開始/停止模擬 | 電腦上正常；iPad 上一開始完全按不動（見下面「iPad 上的問題」） |
| ⏭ 逐格 | 猜是一步一步往前播放（像慢動作單張） | 電腦上沒有特別測試效果差異，看起來時間有小小前進 |
| ↺ 重置 | 把模擬歸零重來 | 按了之後車子回到 s=0, t=0，符合預期 |
| 速度（0.1x ~ 2x 播放速度） | 調整動畫播放快慢 | 切成 2x 後好像沒有很明顯感覺快很多，不太確定是不是真的有效果 |
| 中 / EN | 切換語言 | 按 EN 後整個介面文字變英文，符合預期；切回中也正常 |

## 畫面上的數字

| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| t 時間 | 從開始播放到現在經過的時間 | 有，s |
| s 位移 | 小車現在的位置（相對起點，可正可負） | 有，m |
| d 路程 | 小車走過的總距離（不會因為倒後而變回小數字） | 有，m |
| v 速度 | 小車現在的速度，正代表向右 | 有，m s⁻¹ |
| a 加速度 | 現在的加速度 | 有，m s⁻² |
| A v–t 線下面積 | 猜跟「位移」有關（試了之後發現數值真的跟 s 一樣） | 有，m |
| v̄ 平均速率 / 平均速度 | 到目前為止的平均，一個看方向一個不看方向（猜的，因為兩個常常數值不同） | 有，m s⁻¹ |
| 圖上「斜率 = X.XX m s⁻¹ / m s⁻²」 | 猜是那一點切線的斜率，對應速度或加速度 | 有標單位 |

「位移」和「路程」一開始分不太清楚差在哪，要親自讓車子倒退看到兩個數字不同才搞懂（路程一直增加，位移可以變小）。

## iPad 上的問題

- 一進入頁面（768×1024），三張圖表（s-t、v-t、a-t）和右邊「參數」面板是橫向排在一起的，寬度遠超過 768px，畫面右邊被切掉，要手動左右滑動才能看到 a-t 圖和「顯示」勾選框那一大塊，非常不方便。
- 最嚴重的問題：一開始「▶ 播放」和「⏭ 逐格」按鈕按了完全沒有反應，連續點了 4、5 次，時間 `t` 一直停在 0.00s 不動，感覺整個模擬卡死了。
- 同時「加速度」數字輸入框在這個卡住的狀態下也改不了值：點進去、全選、打 -3、按 Tab，讀數面板的 a 還是顯示原來的 1.00，拖動滑桿也沒反應。
- 後來我隨手點了一下「速度箭嘴」勾選框（跟播放無關），畫面忽然「自己重新排版」，三張圖變成單欄、直向堆疊，不再需要橫向捲動——然後「播放」按鈕就忽然可以用了，加速度輸入框也能改了。這代表 iPad 直向剛進入頁面時的版面是「壞掉」的，要誤打誤撞點一下别的東西才會修好，一般學生根本想不到要這樣做，很可能就放棄了。
- 修好版面之後，其餘操作（改 u、a、T、切模式、拖 v-t 圖圓點）都跟電腦版差不多，一樣要用鍵盤才能切換模式下拉選單，一樣很難精準拖中圓點。
- 另外發現：重新整理網頁（navigate 同一網址）後，u、a、T 時間窗這些設定值不會回到預設，而是保留我上次改過的數字（u=3, a=1, T=5s），畫面也保留上次捲動位置，這點在 iPad 上更容易讓人搞混「這是不是新的一次」。

## 我卡住的地方（按嚴重程度排）

1. **iPad 直向剛打開時，播放/逐格按鈕完全按不動，畫面停在 t=0.00s**，要誤觸別的勾選框讓版面重新排版後才能用——這個完全找不到正常的解決方法，是最嚴重的卡關。
2. **同一狀態下，「加速度」數字框和滑桿都改不了值**，跟上面同時發生，原因應該相同（版面卡住）。
3. **iPad 直向一開始需要橫向捲動才能看到 a-t 圖和部分參數/顯示選項**，就算後來版面修好了，一開始的體驗仍然是「東西被切掉看不到」。
4. **模式下拉選單（電腦和 iPad 都一樣）用滑鼠點選項完全沒反應**，一定要用鍵盤方向鍵/End+Enter 才能切換，一般不熟電腦的學生大概會以為這個選單壞了、卡在原本的模式切不過去。
5. **改變「T 時間窗」會讓整個模擬重置歸零**，跟我原本想像的「只是換一下圖表顯示範圍」不同，讓人措手不及。
6. **v-t 圖上的圓點很難用滑鼠精準拖到想要的高度**，常常拖了幾下都拖不中，畫出來的線容易變形，跟原本想畫的形狀有落差。
7. 找 t=4s 那一刻的速度沒有直接輸入時間跳過去的方法，只能眼睛盯著數字按暫停，抓不準剛好整數秒。

## console 錯誤

用 `read_console_messages`（only errors）檢查了電腦版和 iPad 版兩次，都顯示「No console logs.」，沒有紅色錯誤訊息。
