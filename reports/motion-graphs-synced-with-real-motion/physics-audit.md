# 物理核數：motion-graphs-synced-with-real-motion
規格：reference/11_Book2_難點與3D模擬器規格.md「模擬器 7　運動線圖與真實運動同步」（第 384–420 行），並用 §0.2、§0.3、§4 通用規範　數據：10 個運行、100 010 幀（每運行 10 001 幀，dt = 0.001 s）　第 1 輪

核數方法：不讀 model.ts / plan.ts / Scene.tsx。自寫 Node 程式（scratchpad/audit.js），按規格方程獨立計算每幀的 s、v、a、路程、速率、線下面積、平均速率、平均速度，再與導出數據逐幀比對。
- live 模式：v = u + at，s = ut + ½at²，a = 參數 a；路程 = ∫|v|dt 用解析式（反向時刻 t₀ = −u/a 分段）。
- draw 模式：v(t) 為以 vt 陣列在整數秒為節點的折線，a = 該段斜率；s、路程按每段梯形解析積分（段內過零另分段）。
- 兩種模式的解析解均無數值積分誤差，故容差取相對誤差 1e-6（分母取 max(1, |預期|)）。

## 結論
**不通過**：F1、F2、F3。

- 物理數值全部通過：10 個運行 100 010 幀，八個讀數與我的解析解最大相對誤差 2.1 × 10⁻¹²；規格三條驗證條件全部成立；箭嘴、標籤、縮放係數逐幀無誤。
- F1（低嚴重度，數據）：每個運行在 t 到達時間窗 T 的那一幀，a 讀數與加速度箭嘴變成 0，而 v 仍是 u + aT。10/10 運行皆如此。
- F2（截圖）：四張「試試看」截圖全部截於 t ≈ 4.07 s；情境 1（t > 5 s 才反向）與情境 4（t > 4.5 s 才反向、t = 10 s 才有 −2 m 對 19 m）的反差時刻沒有出現在截圖內；情境 3 的 v = 0 瞬間（t = 0.306 s）亦未截到，但 a–t 水平線橫過 v–t 過零點可見。
- F3（截圖）：scenario-3.png 速度箭嘴（v = −37.1 m s⁻¹）被畫布左緣裁掉，看不到箭頭，該幀不符 §0.2 第 5 條「向量以箭嘴表示（附箭頭）」。

## 6. 守恆量與邊界
- 本模擬無守恆量（外加加速度的運動學）。可核的一致性：area ≡ s（100 010 幀差 0）；∫v dt 對 s 漂移 ≤ 3.4 × 10⁻¹¹ m（10 s）；v² = u² + 2as 漂移 ≤ 4.8 × 10⁻¹⁰。
- a = 0、u = 0（scenario-st-not-path）：10 001 幀全部讀數恰為 0，t = 0 平均速率／平均速度為 0，無 NaN。
- 參數極端（解析估算，數據內無此運行）：u = ±5、a = ±10、T = 20 → \|v\| ≤ 205 m s⁻¹、\|s\| ≤ 2100 m；數值上無溢出，但軌道軸與 s–t 軸需自動縮放到 ±2000 m 量級，小車視覺上會極快離開畫面中央。random-0/3（a ≈ 9、T = 5）已見 s ≈ 129–136 m 正常。
- 隨機負初速、負加速度（random-4：u = −4.66、a = −4.68）：s = −路程全程，速率單調增，無異常。
- 時間窗末端：t ≥ T 後全部量凍結（含 v、s、t），但 a 於 t = T 那一幀提前歸 0（F1）。凍結後箭嘴仍畫出 v ≠ 0 而 a = 0，畫面自相矛盾（小車「停下」但速度箭嘴仍在）。
- 折線節點在 T = 5 時仍有 11 個（random-2 vt 長度 11，T = 5），t > 5 的節點被忽略，無錯誤。

## 7. 規格待釐清
1. 驗證條件三「從未反向時位移讀數與路程讀數必須相等」：物體一直向負方向走時 s = −路程（random-4 全程、random-1 反向前 s = −1.895 對 路程 1.895）。本核數以「大小相等」解讀（通過）。建議規格改為「數值上 \|s\| = 路程」或說明正方向約定。
2. 時間窗到達 T 時的行為規格未定：目前實作把 t 凍結在 T 並把 a 歸 0 而 v 保留。建議規格寫明：到 T 時是「暫停」（全部讀數保持，a 仍為 a），還是「停止」。
3. 「由圖生成運動：學生在 v–t 圖上拖曳畫出線段」：實作是每秒一個節點的折線（manifest 已列 beyondSpec）。折線在節點處 a 不連續（scenario-4 於 t ∈ [4, 5) a = −4，其餘 0），與規格「線段」相容，但 a–t 圖會出現垂直跳變（scenario-4.png a–t 圖 t = 4 s 處），是否可接受待老師定奪。
4. 讀數面板「平均速率」與「平均速度」兩行符號同為 v̄（scenario-3.png：v̄ 平均速率 17.3、v̄ 平均速度 −17.0），只靠中文名區分；規格 §0.2 未規定平均量符號，建議定奪（例如平均速率用 v̄ 而平均速度用向量記號）。
