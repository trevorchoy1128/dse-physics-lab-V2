# 學生試用：http://localhost:5173/#/sim/motion-graphs-synced-with-real-motion
裝置：電腦 / iPad 直向（兩邊都試過，下面分開寫）

## 第一眼
（未按任何東西前）

一打開個網址，個畫面已經自己開始郁緊（小車在一條有刻度的線上面，旁邊有支箭嘴，下面有三個小圖，寫住「s-t圖」「v-t圖」「a-t圖」）。我唔知呢個係咩，睇個標題「運動線圖與真實運動同步」估到係關於小車郁動同啲圖之間嘅關係，但完全唔知第一步應該撳邊度。畫面冇明顯「開始」掣叫我撳，因為佢自己已經喺度播緊。要滾動落去先見到有「暫停/逐格/重置/速度/跳到t=」呢排掣，同埋落面仲有一大堆滑桿（初速、加速度）。如果冇人講，我唔會即刻知道呢啲滑桿係用嚟「操控」小車，仲係淨係睇。

## 老師叫我做的事

### 1. 讓小車先向右行，然後停下來，再倒後行，睇三張圖點變
步驟：撳「暫停」，將「u初速」條滑桿改成 2，「a加速度」條滑桿改成 -1，再撳「播放」（後尾發現「播放」郁得好慢，所以改用「跳到t=」個輸入格直接打 2 同 4 去睇唔同時間嘅畫面）。
期望：小車應該係「向右行，愈行愈慢，停一停，再倒後行」。
實際：
- t=0：小車喺原點，速度=2（向右）。
- t=2：小車行到最右（s=2.00m），car圖示啱啱停喺嗰個位，v-t圖條線啱啱跌到0，s-t圖去到最高點。
- t=4：小車返到原點附近（s≈0），但個車頭已經轉咗方向向左，箭嘴v都指返左，速度讀數係 -2.00 m/s。
- 三張圖嘅樣：s-t圖係一條「先升後跌」嘅拱形線（好似掉波咁）；v-t圖係一條由正到負嘅斜直線，中間駁住0嗰點；a-t圖就成程都係一條水平直線喺 -1 嗰度，冇變過。
呢個效果係啱嘅（睇落係做到「右行→停→倒後」），但我係靠自己諗到用「初速+負加速度」先做到，唔係好直覺，如果冇諗到呢招，淨係喺度撳「播放」等，好難見到成個過程（見下面「卡住」）。
嘗試次數：大概 5-6 次（頭幾次唔知點解個模擬會自己彈返做預設值 u=0,a=1，要重新設定好幾次）。
做到 / 做不到：**做到**（但用咗「跳到t=」呢個「抄捷徑」方法，唔係真係坐定定睇佢由頭play到尾）。

### 2. 找 t = 4 s 時小車嘅速度
步驟：喺上面嘅設定（u=2, a=-1）之下，將「跳到 t=」個輸入格打 4，然後喺個模式面板下面搵到一個叫「讀數」嘅表，入面有一行寫住「v 速度」。
期望：見到一個有單位嘅數字。
實際：讀數表顯示 `v 速度 = -2.00 m s⁻¹`。負號代表方向向左（因為題目話「向右為正」）。
嘗試次數：2 次（第一次唔知「讀數」呢個表喺邊，滾咗好耐先見到）。
做到 / 做不到：**做到**。

### 3. 模式改做「由圖生成運動」，畫一個「先快後慢，然後停住」嘅 v-t 圖，撳播放睇小車係咪咁行
步驟：撳「由圖生成運動：我畫 v-t 圖」個掣，個 v-t 圖度會出現一串圓圈（原來個曲線已經有嘢畫咗，唔係空白）。跟住用手/滑鼠上下拖啲圓圈：頭幾粒拖高（代表快），跟住逐粒拖低，最後幾粒拖到 0 嗰條線（代表停低）。
期望：小車一開始行得快，跟住愈行愈慢，最後停低唔郁。
實際：畫完之後用「跳到 t=」跳去 10s，s-t 圖真係見到「頭段升得快，尾段變晒平」，v-t 圖跌到 0 之後一直係 0，a-t 圖最後都係 0，讀數表 v=0.00, a=0.00。小車喺路軌上面停咗喺 s=6.65m（iPad）／8.50m（電腦，因為我兩次拖嘅位置有少少唔同）嘅位置，冇再郁。睇落係做到題目想要嘅效果。
不過有個怪現象：a-t 圖唔係一條平滑線，而係好多凹凸小方塊（毛刺），唔知係咪我拖得唔夠準，定係程式本身將手畫嘅線攞嚟做微分就會咁。
嘗試次數：畫圖大概拖咗 7-8 粒圓圈，每粒都係一次過就掂，冇太大問題，但拖嗰陣完全唔知自己掂啱咗未，冇即時提示話「你依家改緊边一點」（其實有小字提示，但一開始冇為意）。
做到 / 做不到：**做到**。

## 每個控制項我以為是做甚麼

| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| ⏸ 暫停 / ▶ 播放 | 開始/停止個模擬繼續行 | 撳落去真係會停低同繼續，但「播放」之後個時間郁得好慢，等好耐都好似冇乜嘢郁過 |
| ⏭ 逐格 0.1 s | 估係一格一格咁行，方便睇慢動作 | 冇試好清楚有咩分別，睇落應該係撳一下前進0.1秒，冇播放咁快 |
| ↺ 重置 | 以為會全部歸零（時間、初速、加速度） | 只會將時間 t 拉返做 0，u 同 a 嗰啲我自己設定嘅數值唔會變返預設，同我估嘅唔一樣 |
| 速度（0.1×/0.25×/0.5×/1×/2×） | 播放快慢，1× 應該係實時 | 揀2×之後好似冇乜特別分別（可能因為個1×本身都已經好慢），唔肯定個「×」係咪真係即係嗰個倍數 |
| 跳到 t=（滑桿+輸入格） | 影音檔案嗰種「拉去邊一段」嘅掣 | 好好用，打個數字就即刻跳去嗰個時間，睇到嗰陣嘅位置、速度、三張圖，比撳「播放」等實用好多 |
| 模式：由運動生成圖：我控制小車 | 「我」用滑桿控制車點郁 | 啱，撳咗之後右邊/下面出返 u、a嗰啲滑桿 |
| 模式：由圖生成運動：我畫 v–t 圖 | 自己畫個 v-t 圖，睇車點行 | 啱，撳咗之後 v-t 圖度變咗一堆可以拖嘅圓點 |
| u 初速 | 開始嗰刻嘅速度 | 改咗個數字，v-t圖起點真係跟住郁 |
| a 加速度（可隨時改） | 加速快慢，「可隨時改」估計係話播放緊都可以改 | 改完之後 a-t 圖嗰條線即刻變高度，同埋 v-t 圖嘅斜率都變 |
| T 時間窗 | 估係圖度 x 軸顯示幾多秒 | 冇特登試呢個，睇返圖預設係 10s，冇再改過確認 |
| 顯示：速度箭嘴 | 開/關頂部箭嘴 v 顯示 | 冇撳過，一直開住睇到箭嘴 |
| 顯示：加速度箭嘴 | 開/關頂部箭嘴 a 顯示 | 冇撳過 |
| 顯示：切線（斜率） | 開/關圖上面嗰條虛線（教你點計斜率） | 撳走咗一次，虛線的確唔見咗（但當刻速度啱啱好係0，唔太肯定係咪真係我撳嘅效果） |
| 顯示：線下面積 | 開咗之後 v-t 圖下面塊面積會影住色 | 啱，撳咗之後真係出現一個綠色三角形陰影，仲寫住「面積 = 6.65 m」，同「位移」個數一樣 |
| v-t 圖上面啲圓點（拖動） | 估計係可以自己畫線改變速度 | 啱，上下拖會改個時間點嘅速度數值，拖完個曲線形狀會變 |

## iPad 上的問題

- 版面同電腦（喺呢個瀏覽器視窗嘅闊度）睇落差唔多，都係圖表喺上面，控制列同參數喺落面，冇左右並排嘅版面，唔使橫向滾動。
- 用手指拖 v-t 圖上面嗰啲圓點，反應同用滑鼠差唔多，冧得中，冇特別按唔中嘅情況。
- 全部字睇落夠大，冇睇唔清嘅情況。
- 一樣有「個模擬突然自己reset晒返做預設值」嘅問題（見下面「卡住」），喺iPad同電腦都遇到。
- 冇見到特別畀iPad而設嘅提示或者按鈕，同電腦版基本一樣，只係欄位闊窄唔同。

## 我卡住的地方（按嚴重程度排）

1. **撳「播放」之後，個模擬時間行得極慢**：喺兩部裝置都係咁，等咗成 20 秒真實時間，個計時器 t 先至由 0 行到 0.1-0.15 秒左右，睇落好似卡住咗、又唔係完全冇反應。如果唔識用「跳到 t=」嗰個輸入格直接跳時間，好難用肉眼睇到小車由頭到尾點樣行（尤其係第1題想睇「先右行、停、再倒後」嘅完整過程）。
2. **喺我做緊嘢期間，個網頁會無端端自己重新載入一次，跳返做預設嘅 u=0、a=1，之前自己較好嘅數值全部不見晒**：發生咗好幾次，完全冇警告，搞到我要重新較過晒啲滑桿先可以繼續。唔知係咪個網站本身嘅問題。
3. **「重置」掣唔會重置返啲滑桿數值，只重置時間**：一開始以為撳咗個掣之後啲設定會歸零，令我以為個掣壞咗／冇反應。
4. **搵播放/暫停/跳到t=呢排控制掣要滾好耐先見到**：因為佢哋擺喺三張圖嘅落面，喺一個普通電腦視窗嘅高度，一入嚟見唔到，都以為個網站冇呢啲功能。
5. **見到個位移數字顯示做 `4.37 × 10⁻¹⁵ m`**：本來應該係 0，但用咗好怪嘅科學記數法顯示一粒極細嘅數，第一眼睇好似個網站計錯數／有 bug。
6. **v-t 圖畫完之後，a-t 圖出現好多凹凸唔平嘅「毛刺」**：唔知係我拖得唔夠準，定係呢個係手畫線嘅正常現象，冇解釋話點解會咁。

## console 錯誤

用 `read_console_messages`（含 onlyErrors）睇過，**冇見到紅色錯誤**。全部訊息都係 `[debug]`／`[info]` 級別，內容主要係 `[vite] connecting...` / `[vite] connected.` / `[vite] hot updated: /src/index.css` 呢啲開發伺服器嘅訊息（估計就係解釋點解成個模擬會無端端跳返做預設值——個網頁好似不斷重新連線／重新載入）。冇睇到同呢個物理模擬本身直接有關嘅錯誤字句。
