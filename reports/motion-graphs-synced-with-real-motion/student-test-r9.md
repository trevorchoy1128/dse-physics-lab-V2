# 學生試用：http://localhost:4173/#/sim/motion-graphs-synced-with-real-motion
裝置：電腦（1440×900）/ iPad 直向（768×1024）

## 第一眼
（未按任何東西前）

一打開個頁面，見到最頂有粒橙色小車喺條馬路度企喺度，馬路兩邊有樹，上面寫住「運動線圖與真實運動同步」。落多少少見到三張圖：s-t、v-t、a-t。右邊有一大堆滑桿：初速、加速度、時間窗，仲有幾個checkbox（速度箭嘴、加速度箭嘴、切線、線下面積），下面仲有個「讀數」表列住 t、s、d、v、a 等等。

我第一眼諗：呢個係俾你睇一架車點郁，然後睇住三張圖同步畫出嚟嘅工具。第一步應該按「播放」睇下架車郁唔郁，個「模式」度已經揀咗「由運動生成圖：我控制小車」，感覺係要我自己㩒個加速度掣去玩。冇留意到右邊仲有第二個模式掣「由圖生成運動」，如果唔係老師講，我應該唔會諗到原來仲有一個「自己畫線」嘅玩法。

## 老師叫我做的事

### 1. 時間窗改 40 秒 → 由圖生成運動 → 畫一條頭 20 秒愈嚟愈快、後 20 秒慢慢減速到停嘅 v–t 圖，播放睇車係咪跟到

步驟：先撳「還原預設」，將「時間窗（最長時間）」個輸入格三擊揀晒個數，打「40」再撳 Tab；然後撳「由圖生成運動：我畫 v–t 圖」個掣切去畫圖模式。之後喺 v–t 圖框度用滑鼠喺唔同嘅 t 位置度「按住—拖—放」，想拖出一條先升後跌嘅線。

期望：拖到一條由 0 開始愈升愈高（到 t=20s 最高），然後慢慢跌返落 0（t=40s）嘅折線，撳播放車應該係「愈行愈快，然後慢慢停」。

實際：完全唔係我諗嘅咁！我影落嘅圓點原來靜態時完全冇標籤，見唔到邊粒代表邊一秒，要真係揪住拖佢一吓，先會喺個點度彈出好細隻字嘅「t = 3 s，v = 4 m s⁻¹」呢類提示，唔拖就永遠唔知。

仲有更大問題：我拖一粒點嘅時候，只有果一粒點郁（v 會變），佢隔籬嘅點完全唔會跟住郁，結果我逐粒逐粒咁拖出嚟嘅唔係一條平滑嘅線，而係一排好似心電圖噉嘅尖細山峰（拖完一粒返到 0，跟住去下一粒又係一枝新嘅尖峰），完全唔似我想畫嘅「慢慢升、慢慢跌」。我試過用「一大嗲由左下斜住拖去右上」嘅方式（希望佢好似畫畫咁一路拖一路畫），結果彈出嚟嘅提示永遠都係「t = 0 s」，即係話唔理我拖去邊度，佢揸住嘅個掣個 t 都唔會變、淨係 v 會跟住我放低嗰個高度變。呢個同我諗嘅「拖去邊個位就係嗰個位」完全唔同，非常confusing。

嘗試次數：喺電腦版度試咗成 20 次以上唔同位置、唔同幅度嘅拖拉，reset 咗兩次重新嚟過；iPad 度又試多兩三次，都係一樣嘅問題。

做到 / 做不到：**做不到**。最後撳播放，車頭幾秒有輕微加速，之後就好唔規則咁一時快一時慢，完全冇「後 20 秒慢慢減速到停」呢個效果，同我畫嘅意圖完全對唔上。

**點知每粒圓點代表幾多秒？** 一開始睇畫面完全睇唔出，唯一線索係圖底一行好細字「在圖框內按住任何一秒的位置上下拖，就改變該秒的 v（每格0.5)」，同底下嘅刻度「0s 6s 12s 18s...」——但呢個都冇話總共有幾多粒點/相隔幾多秒，要靠亂咁試拖先大約感覺到。老實講如果唔係刻意去讀嗰行細字，我一個中五學生好可能完全唔會為意，直接照心目中隨便㩒。

### 2. 由運動生成圖播放，途中拉加速度做負數，等車停低再倒後行

步驟：撳「還原預設」，撳「播放」，等車郁一陣，然後將右邊「加速度（可隨時改）」個輸入格三擊改做「-3」再撳 Tab。

期望：睇到車慢慢減速、停一停、再向後行。

實際：完全做到，效果幾清楚。車由向右行慢慢減速，過咗一刻就轉頭向左行，速度讀數同 v-t 圖都清楚由正變負。

回答問題：
- **小車而家喺起點嘅左邊定右邊？** 左邊。
- **點樣睇出（唔靠右邊數字）：** track 畫面上有一支紅色小旗，一開始企喺車正下面（即係起點 s=0），車減速轉頭後架車嘅圖示就慢慢走到去小旗嘅左手邊；再等耐啲，個紅色小旗完全喺畫面消失（跑咗去畫面最右邊），底下馬路嘅刻度數字全部變晒負數（好似 -30、-40、-50 咁），車頭仲有支綠色箭嘴指向左邊，呢啲全部都話緊車一路向左走、已經過咗起點好遠。
- **離起點大約幾多米：** 我等咗大約 4~9 秒（畫面時間），s 讀數喺 -25.6 m 到 -121 m 之間，等愈耐愈遠，大約話「幾十米到成百米」咁上下（睇你等幾耐先撳暫停）。
- **畫面有無字句解釋緊發生咩事：** 有，喺 track 圖上面會見到兩句細字：「箭嘴已按邊空間同步縮短（比例不變）」同「鏡頭跟着小車移動（比例不變）」。呢兩句喺電腦版嘅screenshot度好細好難認得出寫緊乜（要幾乎估），去到 iPad 版（成張圖闊咗）先睇得清楚少少。

### 3. 由運動生成圖，用「跳到 t=」跳去 t=6s，讀 v-t 圖上嘅點同右邊讀數

步驟：撳「還原預設」，喺「跳到 t=」個輸入格打「6」再撳 Tab。

期望：畫面應該即刻跳去 t=6 秒，v–t 圖上應該有粒標示緊嗰一刻嘅點，讀數應該同右邊面板脗合。

實際：完全做到。時間顯示「t = 6.00 s」，v-t 圖上有粒圓點加條虛線指住橫軸 t=6、縱軸大約 6（喺 5 同 10 中間偏下少少），右邊讀數面板「v 速度」寫住「6.00 m s⁻¹」，兩者脗合。

做到。

## 額外留意

- **播放期間有冇嘢突然跳一下？** 有。喺任務 2 度，架車行遠咗之後，track 畫面下面嘅刻度數字（例如由「-2, -1, 0, 1, 2」）喺幾秒之間變成「-48, -38, -28, -18, -8」，感覺好似突然由好近鏡拉到好遠鏡，唔係好順滑，樹同馬路標記亦都要重新擺位。
- **三張圖橫軸（時間）刻度喺 y=0 條線上，睇唔睇得明？負數部分容易唔容易睇？** t 軸（橫軸）本身只會係正數（0 到時間窗上限），呢個冇問題。但縱軸（s、v、a）可以係負，負數個半部分嘅刻度字同正數果邊一樣細，喺電腦版三圖並排嘅細窗度成隻字得幾粒像素，要好眯埋眼先睇到寫緊乜。iPad 版因為圖闊咗好多，睇負數刻度就舒服好多。
- **拖圓點彈出嘅「t=…s, v=…」同我以為嘅有冇出入？** 有出入。我以為拖到邊個橫向位置個 t 就會變成嗰個位置對應嘅秒數，但實測係唔理你點拖，個點嘅 t 係鎖死喺佢原本嗰粒點嘅時間，淨係你放低嗰刻嘅高度（v）先會被記錄落去。即係話橫向拖動基本上冇用，得縱向先有效，呢點同直覺完全唔同。

## 每個控制項我以為是做甚麼

| 控制項（照抄標籤） | 我以為 | 試了之後 |
|---|---|---|
| 模式：由運動生成圖：我控制小車 / 由圖生成運動：我畫 v–t 圖 | 一個係自己揸車郁，一個係自己畫線俾車跟 | 岩，撳落去介面會完全變（有無初速/加速度滑桿 vs 淨係得個v-t畫布可以拖） |
| u 初速 / m s⁻¹ | 車一開始行幾快 | 岩，改完v讀數即時由0變做嗰個數 |
| a 加速度（可隨時改）/ m s⁻² | 車郁緊嗰陣加速有幾勁，正數愈行愈快，負數會令佢慢落嚟甚至倒後 | 岩，播放中改都即時生效 |
| T 時間窗（最長時間）/ s | 一開始唔知，估係「畫面顯示幾耐」 | 岩，改完之後啲圖嘅橫軸最大值即刻變 |
| 速度箭嘴（checkbox） | 開關車頭嗰支話你知緊速度方向嘅箭嘴 | 岩 |
| 加速度箭嘴（checkbox） | 同上，但係畀加速度用 | 岩 |
| 切線（斜率）（checkbox） | 唔知係乜，「切線」呢個詞冇乜頭緒 | 試完先知：開咗會喺s-t/v-t圖度加條虛線同寫個「斜率=X」畀你睇 |
| 線下面積（checkbox） | 估計係v-t圖下面填色 | 岩，開咗v-t圖真係有斜紋填色，仲寫住「面積=18.0 m」，同位移數值一樣 |
| ▶ 播放 / ⏸ 暫停 | 播放動畫 | 岩 |
| ⏭ 逐格 0.1 s | 一格一格咁行 | 岩，撳一次t加0.1s |
| ↺ 重播 | 返去t=0由頭嚟 | 岩 |
| ⟲ 還原預設 | 全部設定返去一開始 | 大致岩，但s-t圖嘅y軸範圍（1000/-1000）冇跟住返去最初嘅（50/-50），呢部分冇還原 |
| 速度（播放速度選單 0.1×~2×） | 控制播放快慢 | 冇特登逐個試，但改完睇落合理 |
| 跳到 t=（滑桿+輸入格） | 跳去指定嗰一秒 | 岩，跳完讀數面板同圖上個點都同步 |

## 畫面上的數字

| 數字 | 我以為是甚麼 | 有沒有單位 |
|---|---|---|
| t 時間 | 現在時刻 | 有，s |
| s 位移 | 離起點幾遠（有方向） | 有，m，有註解解釋 |
| d 路程 | 總共行咗幾遠（唔理方向） | 有，m，有註解解釋 |
| v 速度 | 現在快慢 | 有，m s⁻¹ |
| a 加速度 | 現在加速有幾勁 | 有，m s⁻² |
| v–t 線下面積（等於位移） | 呢個唔開「線下面積」個掣睇落好抽象，成日以為淨係個純數學面積，同「位移」點解會相等一開始唔明；開咗個掣見到陰影先明少少 | 有，m |
| 平均速率（路程÷時間） | 平均行得幾快（唔理方向） | 有，m s⁻¹，但同下面個「平均速度」個名好接近，容易撈亂 |
| 平均速度（位移÷時間） | 平均嗰段時間嘅淨速度（有方向） | 有，m s⁻¹ |

## iPad 上的問題

- 出乎意料，iPad 直向版三張圖係逐張成行咁排、闊晒成個螢幕，數字同線反而**比電腦版睇得清楚**（電腦版三圖並排、每張得返好細一嚿，數字幾乎睇唔清）。
- 冇見到明顯「手指按唔中」嘅嘢，但checkbox（速度箭嘴/加速度箭嘴/切線/線下面積）本身睇落都幾細粒（大約2、30px），如果真係用手指（唔係滑鼠）去撳，估計會唔容易一撳就中。
- 個page要垂直捲動好多次先睇晒track圖、三張線圖同下面成塊參數/讀數面板；改完一個滑桿個page有時會自動scroll返去揸緊嗰個掣附近，搵返啱啱睇緊嗰段要再scroll。
- 冇見到需要橫向捲動嘅地方，闊度岩岩好，冇畀個表或者圖爆出畫面外。
- v-t圖拖點問題喺iPad一樣存在（同電腦版一樣，拖一粒淨係郁嗰粒，t唔會跟手指位置變）。

## 我卡住的地方（按嚴重程度排）

1. 「由圖生成運動」畫線功能完全唔直覺：拖一粒點只會郁嗰粒（縱向），橫向（t）拖極都話返轉頭係鎖死嗰粒原本嘅t；想畫一條平滑嘅線幾乎做唔到，試咗廿幾次都整唔到心目中「頭20秒愈嚟愈快、後20秒慢慢停」嗰種形狀，只能整到一堆好似心電圖嘅尖峰。
2. 圓點靜態時完全冇顯示代表邊一秒，一定要真係拖佢一吓先會彈出好細隻字嘅「t=…, v=…」，唔拖就完全唔知，設計上唔友善。
3. 讀數面板入面「平均速率」同「平均速度」個名好相似，唔望埋註解好容易撈亂，一個係路程一個係位移。
4. 「還原預設」冇將s-t圖嘅y軸刻度範圍還原返（保留咗-1000~1000呢種喺我改完T=40先出現嘅範圍），同其他數值歸零唔一致，感覺個reset做得唔徹底。
5. Track圖上面解釋緊「鏡頭跟住小車」、「箭嘴按比例縮短」嘅字好細，電腦版幾乎睇唔到寫緊乜，容易漏睇。
6. 電腦版三張線圖並排太細，刻度數字（包括負數部分）睇得好辛苦。

## console 錯誤

電腦版同iPad版都用 `read_console_messages`（onlyErrors）檢查過，兩邊都冇見到任何錯誤訊息（No console logs）。
