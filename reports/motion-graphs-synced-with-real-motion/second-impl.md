# 第二實作比對：motion-graphs-synced-with-real-motion（#023）— 第 7 輪（主實作 0.5.0）

積分方法：閉式逐段積分（非數值步進）。兩種模式的 v(t) 都統一表示為折線段列表 {t₀, v₀, m, len}：live 為單一段 v = u + a t；draw 為節點 vt[i] 位於 t = i s 的折線，末節點後接一段斜率 0 的無限段。每段位移為精確二次式 v₀τ + ½mτ²；路程在段內 v 變號點 τ* = −v₀/m 分割後取兩半絕對值相加。步長 dt 只決定輸出幀時刻 t_k = min(k / 1000, T)（整數除法，不累加）。
步長：dt = 0.001 s（取自 index.json）。幀數：60001（t = 0 … 60 s；t ≥ T 後凍結於 t = T）。
運行：index.json 全部 10 個（live × 7：default、scenario-st-not-path、scenario-v-zero-a-not、random-0/1/3/4；draw × 3：scenario-below-axis、scenario-area-not-distance、random-2）。本輪新數據：random-1 的 T = 35.926 s（長時間窗）、random-2 的 T = 13.317 s（draw 模式 T 超出 0–10 s 控制點範圍）。
實作檔（全部重寫，未沿用前任程式碼，只沿用其慣例清單）：`second-impl/model.mjs`（模型）、`run.mjs`（產生各運行 JSON）、`compare.mjs`（逐幀比對 + 凍結／累積誤差／draw 尾段／歸零／主實作自洽專項；結果在 `compare-result.json`、`compare-output.txt`）、`checks.mjs`（量綱、對稱、極限、規格驗證條件；輸出在 `checks-output.txt`）。

## 結論

**一致。** 10 個運行 × 8 個 obs 鍵（s、dist、v、a、speed、area、avgSpeed、avgVel）共 480 萬個幀值全部在 1e-6 容限內；沒有任何鍵、任何幀超限，draw 模式 a 在節點處亦無需動用 2 dt 事件容限（節點容限幀數為 0）。主實作凍結、長時間窗、draw 尾段、歸零規則四項專項檢查全部通過，主實作自身亦滿足規格三條驗證條件。

本輪重點（主實作 0.5.0、T 滑桿 2–60 s、60001 幀）：
1. **凍結幀 t 恰等於 T**：10 個運行的首個 t ≥ T 幀（索引 ⌈T/dt⌉）t 與 T 逐位相等（`===`），主實作最後一步 h = T − t_prev 介於 4.30e-4 與 1.0e-3 s；凍結後直至第 60001 幀 t 恆等於 T，obs 8 鍵無一幀變動。第二實作首個凍結幀索引與主實作完全相同。
2. **長時間窗 T = 35.9 s 無累積誤差、無 NaN**：random-1（|v| 達 186 m s⁻¹、s 達 3269 m）s 的最大絕對誤差 2.67e-9 m（相對 9.5e-11），按 5 s 分箱由 6e-13 緩慢升至 1.4e-9，與 s ≈ ½at² 的量級同步增長（即相對誤差恆在 1e-10 量級，屬雙精度捨入，不是積分累積）。60001 幀 × 8 鍵無非有限值。
3. **draw 模式 T 長於控制點範圍**：random-2（T = 13.317 s，節點止於 10 s）t > 10 s 後 50 000 幀 v 恆為末節點值 0、a 恆為 0、s 恆為 15 m，與第二實作逐位一致。
4. **歸零規則（|x| < 1e-9 → 0）**：主實作為 0 而第二實作 |x| ≥ 1e-9 的情況 0 處；主實作 0 < |x| < 1e-9 未歸零 0 處；第二實作 |x| < 1e-9 而主實作未歸零 0 處；a 未被歸零；speed = |v| 逐幀成立。

## 額外檢查

（`checks.mjs`，只用第二實作模型；輸出見 `checks-output.txt`，全部 true。）

**量綱**
- live：把長度 ×100（m → cm）、時間 ×1000（s → ms）後，u → u·L/Θ、a → a·L/Θ²、T → T·Θ，各讀數在 t·Θ 時刻按 s、dist、area ∝ L，v、speed、avgVel、avgSpeed ∝ L/Θ，a ∝ L/Θ² 縮放，6 個時刻（含 t = 0 與 t = T 凍結幀）全部通過。
- draw：節點固定於整數秒，只能縮放速度單位；vt ×100 後 s、dist、v、a、avgVel 全部 ×100，通過。
- 參數表單位：u [m s⁻¹]、a [m s⁻²]、T [s]，vt [m s⁻¹]；s = ut + ½at² → m；area = ∫v dt → m；avgSpeed = dist/t → m s⁻¹。一致。

**對稱**
- live (u, a) → (−u, −a)：s、v、a、area、avgVel 反號，dist、speed、avgSpeed 不變；三組參數（含 random-1 的 u、a、T）× 9 個時刻（含 T − dt、T、T + 5）通過。
- live 單獨 u → −u（a = 0）與單獨 a → −a（u = 0）：s、v 反號、dist 不變，通過。
- draw vt → −vt：s、v、a 反號，dist、speed、avgSpeed 不變，8 個時刻通過。
- draw 奇對稱折線（scenario-below-axis）：s(5 + τ) = s(5 − τ)、s(10) = 0、dist(10) = 10，通過；主實作數據亦顯示 s(10) = 0、dist(10) = 10.000000000001446。

**極限**

## 規格待釐清

（沿用前幾輪清單，本輪無新增；兩實作在以下各點的慣例相同，故不構成比對差異。）
