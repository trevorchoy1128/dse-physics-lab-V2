# 第二實作比對：motion-graphs-synced-with-real-motion（#023）— 第 5 輪

積分方法：解析逐段積分（兩種模式下 v(t) 都是分段線性，每段 s 為精確二次式 s = v₀τ + ½mτ²；路程在段內以 v = 0 的交叉點 τ* = −v₀/m 分割後取絕對值相加，不用數值積分）。幀時刻以整數除法 t_k = k / 1000 產生；observe 內把 t ≥ T 截斷為 t = T（凍結幀 t 恰等於 T）。
步長：dt = 0.001 s（取自 index.json）。幀數：10001（t = 0 … 10 s）。
運行：index.json 全部 10 個（live × 7：default、scenario-st-not-path、scenario-v-zero-a-not、random-0/1/3/4；draw × 3：scenario-below-axis、scenario-area-not-distance、random-2）。
實作檔：`second-impl/model.mjs`（模型；第 5 輪加入 `simulateMainRule()`——以主實作的累加步進規則 t_{k+1} = t_k + min(dt, T − t_k) 產生幀時刻，供 dt 不整除 T 的測試）、`run.mjs`（產生各運行 JSON）、`compare.mjs`（逐幀比對 + 歸零專項 + 第 5 輪凍結幀專項，結果在 `compare-result.json`、`compare-output.txt`）、`checks.mjs`（額外檢查，輸出在 `checks-output.txt`）。

## 第 5 輪改動（主實作 0.4.0）

① 折線斜率函數的索引夾住在末節點內（之前最後一個樣本回傳 NaN）；② 凍結時把 t 截斷為恰等於 T，最後一步只走到 T（h = T − t），v、s、路程都在 T 計算。歸零規則（|x| < 1e-9 → 0）沿 0.3.0。

第二實作的 observe 自第 1 輪起即為 t = min(t_raw, T)，本輪模型方程無需改動；只補上 `simulateMainRule()` 以複現主實作的步進規則，並在 compare.mjs 加入第 5 輪專項（末幀 t === T、凍結後全部幀 t === T、非有限值掃描、末幀 v/a 與解析期望一致、凍結後 obs 恆定）。

## 結論

**一致。** 10 個運行 × 8 個 key × 10001 幀全部在容限內（全部量皆有解析解，容限 1e-6）。最大絕對誤差 1.92e-11（random-1 的 s / area，|s| ≈ 221 m，主實作雙精度累加誤差）。a 沒有任何一幀差異（含凍結幀與 draw 節點跳變幀），事件時刻容限（2 dt）未動用。幀時刻 t 最大差 1.01e-12（凍結前主實作為累加值；凍結後兩者皆恰為 T，差 0）。

- **每個運行最後一幀 t 恰等於 T**（`=== T` 為 true）；首個 t = T 的幀是第 T/dt 幀（T = 10 → 幀 10000；T = 5 → 幀 5000），之後全部幀 t === T，沒有任何一幀 t ≠ T。

## 不一致的判斷

無不一致。獨立核對（不依賴主實作）：
- 凍結幀 t = T：規格說時間窗 T 結束後運動停止；凍結幀讀數應為 t = T 的解析值。主實作末幀 s、v 與閉式（live：s = uT + ½aT²、v = u + aT；draw：逐段二次式在 T 的值）差 ≤ 2e-11（絕對）、≤ 1e-13（相對），為主實作累加步進的浮點誤差。
- random-2（draw、T = 5 恰在節點）：s(5) = 0.5 + 1.5 + 2.5 + 3 + 3 = 10.5，主實作 10.499999999999998；v(5) = vt[5] = 3，主實作恰為 3；a(T⁻) = vt[5] − vt[4] = 0，兩者相同。
- scenario-below-axis（奇對稱 v–t）：s(10) = 0、dist(10) = 10、v(5) = 0——主實作 s(10) 歸零為 0（真值 1.78e-15）、dist(10) = 10.000000000001442、v(5) = 0。
- 主實作末幀 v 與閉式的 ~5e-12 差（T = 5 的 live 運行）判定為主實作數值累加所致，非規格偏離；第二實作為閉式。兩者差在容限 1e-6 之內，且末幀差分斜率 = a 在雙方成立。

## 額外檢查

### 量綱
- 參數單位：u [m s⁻¹]、a [m s⁻²]、T [s]、vt [m s⁻¹]；輸出 s、dist、area [m]，v、speed、avgSpeed、avgVel [m s⁻¹]，a [m s⁻²]。s = ut + ½at² 每項 [m]；v² = u² + 2as 每項 [m² s⁻²]。
- 數值驗證：長度換 cm（×100）、時間換 ms（×1000），各輸出按各自量綱縮放——通過。draw 只縮放長度——通過。
- 歸零閾值 1e-9 是帶量綱的常數（對 s 是 1e-9 m、對 v 是 1e-9 m s⁻¹），換單位後行為會變；對本模擬器固定 SI 單位無影響，屬顯示層而非物理。

### 對稱
- 反號對稱：(u, a) → (−u, −a) 或 vt → −vt 時，s、v、a、avgVel 反號，dist、speed、avgSpeed 不變——live 與 draw 均通過。歸零規則反號對稱、冪等——通過。
- 時間鏡像：scenario-below-axis 的 vt 對 t = 5 s 奇對稱，s(5+τ) = s(5−τ)、s(10) = 0、dist(10) = 10 m——通過。

### 極限
- a = 0：s = ut、dist = |u|t、a 讀數 0——通過。
- u = 0：s = ½at²、v² = 2as——通過。
- 一般 (u, a)：v = u + at、s = ut + ½at²、v² = u² + 2as 互相一致——通過（亦以主實作全部 live 運行每一幀驗證）。
- draw 每段 s 為二次：二階差分預測第四點吻合；二階差分 / h² = 段斜率 = a 讀數——通過。
- draw 超出末節點（T = 20、3 節點；以及 dt = 0.0007 的 T = 20、11 節點案例）：v 保持末值、a = 0、s 線性、無 NaN——通過。
- t = 0：s = dist = area = avgSpeed = avgVel = 0，v = u，a = a——通過。
- a 極大（1e6）：s = 2e6——通過。靜止（u = a = 0）：s = dist = v = 0——通過。
- dt 不整除 T（dt = 0.0007，T = 5 / 10 / 20）：最後一步 h = T − t < dt，凍結幀 t === T，凍結幀讀數與 observe(p, T) 逐鍵完全相同——通過（見上表）。

### 規格驗證條件（用主實作輸出逐幀檢驗）
- v–t 線下面積 = s–t 位移（area === s）——10 運行全部通過。
- 勻加速三式互相一致——全部 live 運行通過。
- 未反向時 dist = |s|、反向後 dist > |s|——全部通過（反向的運行：scenario-below-axis 5 s、scenario-v-zero-a-not 0.306 s、scenario-area-not-distance 4.5 s、random-1 0.845 s）。
- speed = |v|、avgSpeed·t = dist、avgVel·t = s——全部通過。

## 規格待釐清
1. （第 5 輪新增，非問題）主實作末幀 v 與閉式 u + aT 差 2e-12 … 5e-12，顯示 v 是逐步累加而非在 T 以閉式計算。若「v、s、路程都在 T 精確計算」意在閉式，可在凍結時改以 v = u + aT、s = uT + ½aT² 直接寫入；目前差異在容限內，不需改動。
2. 歸零（|x| < 1e-9 → 0）是顯示層慣例，規格沒有；已驗證它只影響真值 < 1e-9 的值。建議在規格或 manifest 註明閾值與適用鍵（不含 a；speed 取歸零後的 |v|）。
3. avgVel 與 s 各自獨立歸零：若 t < 1 且 1e-9 ≤ |s|/t 而 |s| < 1e-9，會出現 s = 0 但 avgVel ≠ 0（本組運行未發生，最小非零值 5e-7）。
4. （沿前輪）規格沒有參數表；u、a 範圍、T 選項、draw 節點間距（1 s）與節點數（11）皆由開發端定。
5. （沿前輪）draw 模式 T = 20 而 vt 只到 10 s 時，10 s 後 v 保持末值、a = 0（兩實作一致，規格未寫）。
6. （沿前輪）avgSpeed / avgVel 在 t = 0 取 0（兩實作一致，規格未定義）。
7. （沿前輪）draw 節點處 a 不連續：未凍結時整數秒幀取右段斜率、凍結幀（T 恰在節點）取左段斜率——random-2 已驗證兩實作一致；第 4 輪待釐清「凍結幀 v 用未截斷 t 在右段插值」本輪已由主實作 0.4.0 消除。
