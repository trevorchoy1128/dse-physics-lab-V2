# 慣性與牛頓運動第一定律

## 觀察步驟
1. 打開時是 2024 年 DSE 卷一乙部第 3 題的情景：0.20 kg 的方塊在光滑桌面上受 0.30 N 的水平力，由 A 走向 B（0.75 m），B 之後桌面粗糙。方塊已在動。
2. 按右邊的「已放手」：紫色施力箭嘴即時消失，綠色速度箭嘴長度不變；讀數「作用於物體的力」由 3 支變 2 支，「淨力」是 0 N。這就是該題 (b) 部的正確受力圖。
3. 讓方塊走過 B 點再放手：橙色摩擦箭嘴出現，指向後，方塊減速至停。把「後段桌面的摩擦力」拖到 0 重播，方塊永遠等速前進。
4. 先把「後段桌面的摩擦力」拖到 0，再開「第二個方塊」：兩個質量不同的方塊受同一推力，看誰加速快；放手後兩者速度各自不變（若後段仍有摩擦，過了 B 點兩者都會減速，那是摩擦的作用）。按「試試看」的「重的物體滑得比較遠」會自動設好這組參數。
5. 換情景「桌布實驗」：看衝量條與讀數 Δ*t*、*J*、Δ*v*；把抽出速率由 5 改為 10，再改為 1.0。
6. 換情景「巴士上的乘客」：等巴士急煞，看乘客身上有沒有向前的箭嘴；再試「握扶手」。
7. 換情景「太空中的飛船」：把引擎推力調到 2 N，播放後按「關」，看速度讀數。

## 理論
牛頓運動第一定律：每個物體都保持靜止或勻速運動的狀態，除非受到淨力作用。力不是維持運動的原因，力是**改變**運動的原因；淨力為零時，速度的量值和方向都不變，靜止只是「速度為零」這個特例。

學生的日常經驗指向相反的結論：推車要一直推，車才會一直走。這是因為日常中摩擦從來沒有真的消失。課本 §3.2 用氣墊導軌（實驗 3a）去拆這個想法；本模擬讓你把摩擦力一直拖到 0。2024 年的考評局評語指出，能力較差的考生在 (b) 部的受力圖上「錯誤地保留已被移除的水平施力」——看見物體仍在動，就補回一支不存在的力。

「沒有淨力」不等於「沒有力」：桌上靜止的方塊受重量與法向反作用力兩支力，只是它們平衡。慣性是物體保持原有運動狀態的傾向，只由質量決定，與速度無關；質量是慣性的量度。

摩擦永遠與相對接觸面的運動（或運動趨勢）方向相反。滑動時大小等於你設定的摩擦力 *f*；相對靜止時摩擦只會大到剛好抵消其他力，不會超過 *f*。接觸面本身在加速（巴士地板、桌布）時，摩擦最多只能給物體 *f*/*m* 的加速度：地板或布的加速度不超過 *f*/*m*，物體跟着走；超過，物體相對滑動。（DSE 不用摩擦係數 *μ*，本模擬全部直接用摩擦力 *f*。）

桌布實驗：物件受布的摩擦 *f*布 作用 Δ*t*，獲得衝量 *J* = *f*Δ*t* = *m*Δ*v*。抽得越快，Δ*t* 越短，Δ*v* 越小。當 *v*布² ≤ 2(*f*布/*m*)*L* 時，物件在布抽出之前已追上布速，桌布抽不出。

## 常見混淆
### 「物體在動，就一定有一支力在推住它」
- 為何會這樣想：日常推車要一直推；2024 年考生把已撤去的力畫回受力圖。
- 試試看：[moving-needs-force]
- 正確理解：放手後水平方向沒有任何力，速度仍然不變。運動不需要力維持。

### 「沒有力，物體就會慢慢停下來；停下來是因為力用完了」
- 為何會這樣想：從未見過沒有摩擦的情況。
- 試試看：[stop-is-friction]
- 正確理解：停下來的原因是摩擦這支淨力；摩擦力 *f* = 0 時物體永遠等速前進。「力用完」這回事並不存在。

### 「物體慢慢停下來是因為慣性」
- 為何會這樣想：把「慣性」當成一種令物體停下的阻力。
- 試試看：[stop-not-inertia]
- 正確理解：慣性令物體**保持**運動狀態；沒有摩擦，三艘飛船各自保持原速，誰也不會停。

### 「有推力物體就一定加速；勻速一定要有淨力」
- 為何會這樣想：把「有力」與「有加速度」綁在一起。
- 試試看：[constant-v-zero-net]
- 正確理解：施力等於摩擦時淨力為零，物體勻速。拖車以恆速度前進，拉力等於摩擦。

### 「靜止即是沒有力」
- 為何會這樣想：看不見力，只看見不動。
- 試試看：[rest-not-no-force]
- 正確理解：靜止的方塊受重量與法向反作用力，兩者等長反向，淨力才是零。

### 「巴士急煞時有一股力把乘客推向前」
- 為何會這樣想：身體的感覺像被推。
- 試試看：[bus-brake]
- 正確理解：乘客身上只有向後的摩擦，沒有向前的力；是巴士慢了而乘客保持原速。考試作答一律用地面（慣性）視角。

### 「巴士起步時乘客被拋向後」
- 為何會這樣想：相對巴士，乘客的確向後移動。
- 試試看：[bus-start]
- 正確理解：地面視角下乘客留在原地，是地板從腳下向前走；摩擦夠大時才把乘客向前帶動。

### 「重的物體慣性大，一旦推動了也難停，所以滑得比較遠」
- 為何會這樣想：把「難改變速度」誤解為「動得更久」。
- 試試看：[heavy-not-farther]
- 正確理解：放手後兩個方塊的速度各自不變，誰也不會滑得更遠。慣性大只是速度較難改變。

### 「慣性與速度有關；靜止的物體沒有慣性」
- 為何會這樣想：把慣性和「衝力」混為一談。
- 試試看：[inertia-not-speed]
- 正確理解：慣性只由質量決定。同一推力下，靜止的和運動中的飛船速度變化完全一樣。

### 「桌布抽得快，物件留在原地是因為它來不及反應」
- 為何會這樣想：用日常語言代替物理量。
- 試試看：[cloth-impulse]
- 正確理解：抽得快，摩擦作用時間 Δ*t* 短，衝量 *J* = *f*Δ*t* 小，物件獲得的 Δ*v* 小。抽得太慢，物件追上布速，一起走。

### 「太空中沒有重力，所以太空船要開着引擎才能前進」
- 為何會這樣想：以為前進需要推力維持。
- 試試看：[engine-off]
- 正確理解：關掉引擎後沒有任何力，飛船以原速繼續前進；引擎只用來改變速度。

## 觀察重點
1. 放手一刻：施力箭嘴消失，速度箭嘴長度不變，v–t 線由斜線轉為水平線；「作用於物體的力」由 3 支變 2 支。
2. 粗糙段：橙色摩擦箭嘴與速度反向，停下後摩擦箭嘴消失，不會把方塊推向後。
3. 施力等於摩擦時，紫、橙兩支箭嘴等長反向，淨力 0 N，方塊勻速。
4. 桌布：抽得越快，衝量條越短；抽得太慢，物件與布一起走。
5. 巴士急煞：乘客的 v–t 線保持水平，巴士的線向下斜，兩線分開就是「向前衝」；乘客身上沒有向前的箭嘴。
6. 太空：關引擎後速度讀數紋絲不動，燃料消耗為零。

## 教師備註
- 規格：`reference/13_024_慣性與牛頓運動第一定律_模擬器規格.md` v0.4（v0.3 老師 2026-09-07 核准；v0.4 摩擦改為摩擦力 *f*）。
- 老師決定（2026-09-11，全站）：DSE 沒有教摩擦係數 *μ*，摩擦一律由學生直接設定摩擦力 *f*（N）；*μ* 不出現在滑桿、讀數或圖例。摩擦力滑桿的範圍與預設值由開發端按舊預設換算取整，待老師核准。
- 老師決定：桌布物件不設質量滑桿（固定 1.0 kg）。課本圖 3.2e 以「滿樽質量大、慣性大所以留下」解釋，但空樽倒下的真正原因是重心高、底面窄（傾倒，見 S4）；摩擦改為直接設定 *f* 之後，質量對 Δ*v* 的影響不在本模擬討論。模型內仍保留質量，供驗證條件 12（*J* = *f*Δ*t* = *m*Δ*v*）測試。
- 老師決定：乘客簡化為在地板上滑動的物體（真實情況是繞腳的傾倒，受力分析相同）；巴士只有地面視角，不畫虛擬力；靜摩擦上限等於滑動時的摩擦力。
- 規格以外、由開發端定的常數（待老師定奪）：光滑段 0.75 m（2024 卷一乙部 Q3）；乘客質量 60 kg；三艘飛船初速 0、+2、−2 m s⁻¹；燃料消耗率示意 0.05 × *F*引擎 kg s⁻¹；情景 1、4 時間窗 12 s。
- 術語表未收錄、待老師定奪：glider（氣墊導軌上的滑行物）、seat belt／headrest（安全帶／頭枕）、Galileo's law of inertia（伽利略慣性定律）、impetus theory（衝力理論）。法向反作用力的符號沿用課本的 *R*。
