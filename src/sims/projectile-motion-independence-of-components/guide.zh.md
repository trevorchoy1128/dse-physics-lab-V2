# 拋體運動：水平與垂直的獨立性

## 觀察步驟
1. 畫面打開時球已由發射器射出（*u* = 15 m s⁻¹，*θ* = 40°）。看着它：地面上的影子等距前進（水平勻速），牆上的高度影子上升時愈來愈密、下降時愈來愈疏（垂直加速）。
2. 看下面三個同步視窗：側視投影只見垂直運動（愈落愈快），俯視投影只見水平運動（地面影子間距相等），動能—時間圖顯示動能先減後增、不會歸零。
3. 拖「跳到 *t* =」到最高點，讀 *v*ₓ、*v*ᵧ 與合速率；再拖到落地瞬間，比較落地速率與初速。
4. 改變投射角 *θ*、初速 *u*、發射高度 *h*，看射程與飛行時間怎樣變。把 *g* 改為 1.6（月球）或 3.7（火星），看路徑形狀。
5. 開啟「各角度射程比較」，看 15°、30°、45°、60°、75° 的路徑一起畫出來。
6. 右欄「第二顆球」選「同時自由下落」或「水平初速加倍」，看兩球是否同一刻落地。
7. 開啟「頻閃照片模式」，側視視窗變成黑底的頻閃照片，像 DSE 試卷那樣只留每 0.1 s 的影像。
8. 開啟「空氣阻力」，看 *v*ₓ 不再不變、路徑不再對稱；把質量 *m* 調大，阻力的影響變小。

## 理論
「兩個方向的運動互不影響」這句話背得出，但一計算就把合速率代入垂直方向的方程。另一大難點是「最高點」：以為最高點速度為零（那是垂直上拋，不是拋體），於是把最高點動能算成零。

忽略空氣阻力時，拋體只受重量作用，加速度恆為 *g*、向下。把運動分成兩個方向：

- 水平方向沒有力，*a* = 0，是勻速運動：*x* = *u* cos *θ* · *t*
- 垂直方向 *a* = −*g*，是勻加速運動：*y* = *h* + *u* sin *θ* · *t* − ½*gt*²，*v*ᵧ = *u* sin *θ* − *gt*

由地面發射、落回同一水平面時：飛行時間 *t* = 2*u* sin *θ* / *g*，射程 *R* = *u*² sin 2*θ* / *g*，最高點 *H* = *h* + *u*² sin²*θ* / 2*g*。

兩個方向共用同一個 *t*，這就是它們唯一的聯繫。飛行時間由垂直運動決定；水平初速只決定飛得多遠，不影響在空中多久。

## 常見混淆
### 「速度較大的拋體，飛行時間較長」
- 為何會這樣想：日常經驗中「用力」既飛得遠又飛得久，把兩件事混在一起。
- 試試看：[same-landing]
- 正確理解：一顆水平射出、一顆由靜止釋放，全程同一高度、同一刻落地；把第二顆改為水平初速加倍也一樣。飛行時間只由垂直運動（*h*、*u* sin *θ*、*g*）決定。

### 「最高點速度為零」
- 為何會這樣想：把拋體當成垂直上拋。垂直上拋在最高點確實停住，但拋體仍有水平速度。
- 試試看：[top-not-zero]
- 正確理解：最高點 *v*ᵧ = 0，但 *v*ₓ = *u* cos *θ* 不變，速度箭嘴變成水平。動能最低但不是零，等於 ½*mv*ₓ²。

### 「拋體在空中受到一個向前的力」
- 為何會這樣想：球一直向前走，直覺以為有東西推着它。
- 試試看：[no-forward-force]
- 正確理解：離開發射器後，唯一的力是重量，向下。球向前是因為水平方向沒有力改變它的 *v*ₓ（牛頓第一定律）。

### 「加速度在最高點為零」
- 為何會這樣想：最高點 *v*ᵧ = 0，就以為「不動 = 不加速」。
- 試試看：[a-at-top]
- 正確理解：加速度由力決定。重量全程不變，所以 *a* = *g* 向下全程不變，最高點也一樣。

### 「射程角度愈大愈遠」
- 為何會這樣想：角度大，飛得高、飛得久，以為也飛得遠。
- 試試看：[range-45]
- 正確理解：射程 *R* = *u*² sin 2*θ* / *g*，在 45° 最大；*θ* 與 90° − *θ* 的射程相同。角度大只是換來高度與時間，水平速度卻變小。

## 觀察重點
1. 「同時落地」：兩顆球（或一顆自由下落、一顆水平拋出）的垂直位置永遠相同，側視投影的高度連線全程水平。
2. 頻閃影像：俯視投影中地面影子的水平間距相等；側視投影中垂直間距上升時逐格縮小、下降時逐格增大。
3. 動能—時間圖：動能不會歸零，最低點等於 ½*mv*ₓ²（虛線）。
4. 落地瞬間（同一水平面）：合速率等於初速，上升時間等於下降時間。
