# 運動線圖與真實運動同步

## 觀察步驟
1. 預設是「由運動生成圖」：小車由靜止開始，以 *a* = 1 m s⁻² 加速。看着 s–t、v–t、a–t 三張圖同時畫出。
2. 播放途中把「加速度」滑桿拉到負數，看小車減速、停下、倒行時三張圖怎樣變。
3. 開啟「切線（斜率）」：s–t 圖上切線的斜率就是 *v*，v–t 圖上切線的斜率就是 *a*，與讀數面板對照。
4. 開啟「線下面積」：v–t 圖由 0 到現在的面積，與「位移」讀數對照。
5. 把「模式」改為「由圖生成運動」，拖動 v–t 圖上的圓點畫出你想要的 v–t 圖，按播放，看小車是否如你所想。

## 理論
線圖的斜率與線下面積各代表甚麼，是 DSE 出現次數最多的技能之一。s–t 圖的斜率是速度 *v* = Δ*s*/Δ*t*；v–t 圖的斜率是加速度 *a* = Δ*v*/Δ*t*；v–t 圖的線下面積是位移 *s* = ∫*v* d*t*。時間軸以下的面積為負，面積的總和是位移，不是路程。

勻加速運動的三條方程：*v* = *u* + *at*、*s* = *ut* + ½*at*²、*v*² = *u*² + 2*as*。三條方程互相一致，任何一刻都同時成立。

## 常見混淆
### 「v–t 圖上的線在時間軸以下即是減速」
- 為何會這樣想：把「數值向下」讀成「慢下來」。
- 試試看：[below-axis]
- 正確理解：線在軸下表示速度為負，即向反方向運動；減速還是加速要看 *v* 的大小是否減少，或看 a–t 圖。

### 「s–t 圖是物體走過的路徑」
- 為何會這樣想：圖形有起伏，像一條路。
- 試試看：[st-not-path]
- 正確理解：物體沿直線軌道運動，圖形只是位移隨時間的變化。靜止時 s–t 圖是水平線，物體卻沒有移動。

### 「速度為零則加速度為零」
- 為何會這樣想：把「停下來」和「不再加速」混為一談。
- 試試看：[v-zero-a-not]
- 正確理解：豎直上拋在最高點 *v* = 0，加速度仍為 9.81 m s⁻²，方向向下；下一刻速度立即改變。

### 「線下面積永遠是走過的路程」
- 為何會這樣想：只見過全程在軸上的例子。
- 試試看：[area-not-distance]
- 正確理解：軸下的面積為負，面積總和是位移；路程要把每段面積取絕對值相加。面板同時顯示「位移」和「路程」兩個讀數。

## 觀察重點
1. 三張圖的最右端永遠對應小車此刻的位置、速度和加速度。
2. s–t 圖切線的斜率等於 v–t 圖此刻的高度；v–t 圖切線的斜率等於 a–t 圖此刻的高度。
3. 小車反向的一刻，v–t 圖穿過時間軸，s–t 圖出現轉折點，路程與位移從此不同。
